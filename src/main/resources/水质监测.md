# 水质监测接口文档（前端对接）

> 面向前端页面 / H5 / 三维系统对接，生产环境路径统一加 `/hltgq-site` 前缀，需登录会话（请求头 `X-Session-Id`）。
> 模块：水质监测站六项指标（氨氮 NH₃-N / COD / BOD₅ / TP 总磷 / TN 总氮 / 溶解氧 DO）的实时监测与历史分析。

---

## 1. 页面模块与接口对应

| 页面区块 | 接口 |
|---|---|
| 监测总览（每站最新一条 + 该站阈值配置） | [3.1 最新数据](#31-最新数据首页) |
| 趋势图（有机污染曲线 / 营养盐占比折线 / DO 趋势，三图共用） | [3.2 趋势](#32-趋势2-小时级三图共用) |
| 历史明细表格（分页） | [3.3 历史数据](#33-历史数据分页) |
| 站点下拉（有水质数据的站点） | [3.4 站点列表](#34-站点列表下拉) |

---

## 2. 通用约定

| 项目 | 约定 |
|---|---|
| 前缀 | 生产环境统一加 `/hltgq-site`，如 `/hltgq-site/water-quality/monitoring` |
| 鉴权 | 需登录会话，请求头携带 `X-Session-Id`；未登录返回 401 |
| 时间格式 | URL 参数 `yyyy-MM-dd HH:mm:ss`（空格用 `+` 或 `%20` 编码）；响应为 ISO 格式 `yyyy-MM-ddTHH:mm:ss` |
| 站点标识 | 查询/回传用 `stcd` 参数：测站编码（如 `9000000142`）；列表接口输出的 `site` / 下拉输出的 `code` 即为该值，可直接回传 |
| 数值精度 | 统一截断 3 位小数返回 |
| `null` | 表示无数据/未上报/无法计算，前端自行空值展示 |
| `-9991` | 设备异常（通讯故障哨兵），后端透传，前端展示 `--`；趋势聚合不参与计算 |
| `-999` | 设备不存在，后端已转 `null` 返回 |
| `0` | 属正常值（低于检出限），照常展示，见 §6 |

---

## 3. 接口

### 3.1 最新数据（首页）

> 每个站点返回最新一条水质记录，含站点名称/编号、监测时间、氨氮/COD/BOD₅/TP/TN/溶解氧及该站水质阈值行。支持按站点（多选）和日期区间筛选。

**请求方式**：`GET`

**请求路径**：`/water-quality/monitoring`

#### 请求参数

| 参数 | 必填 | 格式 | 说明 |
|------|:--:|------|------|
| stcds | 否 | String | 站点标识列表，多个逗号分隔。不传 = 全部水质站点 |
| startDate | 否 | `yyyy-MM-dd` | 起始日期（含当日 00:00 起） |
| endDate | 否 | `yyyy-MM-dd` | 截止日期（含当日全天） |

#### 调用示例

```
/hltgq-site/water-quality/monitoring
/hltgq-site/water-quality/monitoring?stcds=9000000142
/hltgq-site/water-quality/monitoring?startDate=2026-09-09&endDate=2026-09-09
```

#### 响应格式

```json
[
  {
    "stcd": "9000000142",
    "site": "9000000142",
    "siteId": "uuid-站点档案主键",
    "stnm": "某某水质站",
    "tm": "2026-09-09T18:43:44",
    "nh3n": 0.088,
    "codcr": 0.0,
    "bod5": null,
    "tp": 0.038,
    "tn": 0.24,
    "dox": 4.283,
    "thresholds": [
      { "id": "uuid-xxx", "site": "uuid-站点档案主键", "device": "", "type": "#8#", "remark": "水质", "threshold": 2.0, "guarantee": null, "num": 5.0 }
    ]
  }
]
```

#### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String | 测站编码（站点无编码时为 `null`，前端留空） |
| site | String | 站点标识（= stcd 或站点 UUID 兜底），查询/筛选回传用 |
| siteId | String | 站点档案主键（前端一般不直接用，阈值行内部关联） |
| stnm | String | 站点名称 |
| tm | String | 监测时间（ISO 格式，= 设备采样时间） |
| nh3n | Number | 氨氮 (mg/L) |
| codcr | Number | COD 化学需氧量 (mg/L) |
| bod5 | Number | BOD₅ 五日生化需氧量 (mg/L)，设备不上报恒为 `null` |
| tp | Number | TP 总磷 (mg/L) |
| tn | Number | TN 总氮 (mg/L) |
| dox | Number | 溶解氧 (mg/L) |
| thresholds | Array | 该站水质阈值行（无配置时为空数组 `[]`），字段说明见 §5 |

#### 边界说明

- 每站仅返回一条（按监测时间最新）；筛选区间内无数据的站不出现
- 无任何数据时返回空数组 `[]`（如站点尚未上报，页面空态展示由前端处理）

### 3.2 趋势（2 小时级，三图共用）

> 返回 2 小时间隔（桶起点对齐偶数小时 00:00/02:00/…，跨天连续）的六指标聚合均值与阈值行，**三张图由同一接口取数**，前端按指标自行绘制：
> - **有机污染指标趋势曲线图**：x 轴 = hour，y 轴 = COD（codcr）、BOD（bod5）
> - **营养盐相对限值占比折线图**：y 轴 = 氨氮占比、总氮占比、总磷占比；占比 = 实测值 ÷ 限值 × 100%
> - **溶解氧（DO）24h 趋势图**：y 轴 = 溶解氧（dox），DO 为**越低越危险**

**请求方式**：`GET`

**请求路径**：`/water-quality/trend`

#### 请求参数

| 参数 | 必填 | 格式 | 说明 |
|------|:--:|------|------|
| stcd | **是** | String | 站点标识（测站编码，取自站点列表 `code`） |
| startTime | 否 | `yyyy-MM-dd HH:mm:ss` | 起始时间，默认 24 小时前（自动对齐到偶数小时） |
| endTime | 否 | `yyyy-MM-dd HH:mm:ss` | 截止时间，默认当前时间（自动对齐到偶数小时） |

#### 调用示例

```
/hltgq-site/water-quality/trend?stcd=9000000142
/hltgq-site/water-quality/trend?stcd=9000000142&startTime=2026-09-09+00:00:00&endTime=2026-09-10+00:00:00
```

#### 响应格式

```json
{
  "stcd": "9000000142",
  "stnm": "某某水质站",
  "startTime": "2026-09-09T00:00:00",
  "endTime": "2026-09-10T00:00:00",
  "thresholds": [
    { "id": "uuid-xxx", "site": "uuid-站点档案主键", "device": "", "type": "#8#", "remark": "水质", "threshold": 2.0, "guarantee": null, "num": 5.0 }
  ],
  "points": [
    { "hour": "2026-09-09 00:00", "nh3n": 0.09, "codcr": 0.0, "bod5": null, "tp": 0.04, "tn": 0.24, "dox": 4.28 },
    { "hour": "2026-09-09 02:00", "nh3n": null, "codcr": null, "bod5": null, "tp": null, "tn": null, "dox": null }
  ]
}
```

#### 字段说明

**顶层字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String | 站点标识 |
| stnm | String | 站点名称（站点无数据时回退为 stcd） |
| startTime | String | 查询起始时间（对齐偶数小时后，ISO 格式） |
| endTime | String | 查询截止时间（对齐偶数小时后，ISO 格式） |
| thresholds | Array | 该站水质阈值行（无配置时为空数组），字段说明见 §5 |
| points | Array | 2 小时级数据点（严格 2h 步长对齐偶数小时，**无缺失点**） |

**thresholds[].字段**（阈值配置行，见 §5）

**points[].字段**

| 字段 | 类型 | 说明 |
|------|------|------|
| hour | String | 桶标签 `yyyy-MM-dd HH:00`（恒为偶数小时） |
| nh3n | Number | 桶内氨氮均值 (mg/L)。该桶无有效数据为 `null` |
| codcr | Number | 桶内 COD 均值 (mg/L)。无有效数据为 `null` |
| bod5 | Number | 桶内 BOD₅ 均值 (mg/L)。恒为 `null`（设备不上报） |
| tp | Number | 桶内 TP 均值 (mg/L)。无有效数据为 `null` |
| tn | Number | 桶内 TN 均值 (mg/L)。无有效数据为 `null` |
| dox | Number | 桶内 DO 均值 (mg/L)。无有效数据为 `null` |

#### 前端图表用法

```javascript
const resp = await fetch(`/hltgq-site/water-quality/trend?stcd=${stcd}`);
const { points, thresholds } = await resp.json();

// ECharts：三个图共用 points，仅 series 取值不同
// 图1 有机污染曲线：x = hour，y = codcr / bod5
// 图2 营养盐占比折线：y = nh3n/tp/tn 分别 / 对应限值 × 100（限值口径见 §5）
// 图3 DO 24h 趋势：y = dox（越低越危险，预警线取自对应指标阈值行）
chart.setOption({
  xAxis: { type: 'category', data: points.map(p => p.hour.slice(5, 16)) }, // "MM-DD HH:00"
  series: [
    { name: 'COD', type: 'line', connectNulls: false, data: points.map(p => p.codcr) },
    { name: 'BOD5', type: 'line', connectNulls: false, data: points.map(p => p.bod5) }
  ]
});
```

#### 边界说明

- points 完整覆盖 [startTime, endTime] 每 2 小时一个点；**无数据的桶各指标为 `null`**（图表 `connectNulls: false` 断线，勿补 0）
- 起止时间自动对齐偶数小时，传奇数小时会回退 1 小时

### 3.3 历史数据（分页）

> 分页返回指定站点的历史记录（按监测时间倒序），列表字段同 [3.1](#31-最新数据首页)，不携带阈值。

**请求方式**：`GET`

**请求路径**：`/water-quality/history`

#### 请求参数

| 参数 | 必填 | 格式 | 说明 |
|------|:--:|------|------|
| stcd | **是** | String | 站点标识（测站编码） |
| startTime | 否 | `yyyy-MM-dd HH:mm:ss` | 起始时间（含） |
| endTime | 否 | `yyyy-MM-dd HH:mm:ss` | 截止时间（含） |
| page | 否 | long | 页码，默认 1 |
| size | 否 | long | 每页条数，默认 10 |

#### 调用示例

```
/hltgq-site/water-quality/history?stcd=9000000142&page=1&size=10
/hltgq-site/water-quality/history?stcd=9000000142&startTime=2026-09-09+00:00:00&endTime=2026-09-10+00:00:00
```

#### 响应格式

```json
{
  "total": 150,
  "current": 1,
  "size": 10,
  "pages": 15,
  "records": [
    {
      "stcd": "9000000142",
      "site": "9000000142",
      "siteId": "uuid-站点档案主键",
      "stnm": "某某水质站",
      "tm": "2026-09-09T18:43:44",
      "nh3n": 0.088,
      "codcr": 0.0,
      "bod5": null,
      "tp": 0.038,
      "tn": 0.24,
      "dox": 4.283,
      "thresholds": null
    }
  ]
}
```

#### 字段说明

分页结构 `total/current/size/pages/records` 为通用分页结构；`records[].字段` 同 [3.1 字段说明](#31-最新数据首页)（本接口不装配阈值，`thresholds` 恒为 `null`）。无数据时 `total=0`、`records=[]`。

### 3.4 站点列表（下拉）

> 返回有水质数据的所有站点，供搜索/下拉选择（含历史数据站的测站编码与名称）。

**请求方式**：`GET`

**请求路径**：`/water-quality/sites`

无参数。

#### 响应格式

```json
[
  { "code": "9000000142", "name": "某某水质站" },
  { "code": "uuid-无编码站点兜底", "name": "另一水质站" }
]
```

#### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 站点标识（下拉选中值，回传给各接口的 `stcd` 参数） |
| name | String | 站点名称 |

#### 边界说明

- 站点列表为**数据驱动**（有水质的站才出现）：新站点/新设备接入后首批报文入库即出现；页面无数据时列表为空属预期

## 4. 三图与指标关系（业务口径）

| 图 | 指标组合 | 说明 |
|---|---|---|
| 有机污染指标曲线 | codcr（COD）、bod5（BOD₅） | 直出浓度值；bod5 暂恒为 null 只有一条线 |
| 营养盐相对限值占比折线 | nh3n / tp / tn | 每点 = 实测值 ÷ 对应指标限值 × 100%；限值与预警线由前端按该指标阈值行取值换算（见 §5），各指标限值也可按业务标准限值表取值 |
| 溶解氧 DO 趋势 | dox | 直出浓度值；**越低越危险**，阈值预警线取对应指标阈值行（DO 类限值语义：低于 guarantee/num 为超标方向） |

---

## 5. 阈值行说明（thresholds[].字段）

阈值配置行即列表/趋势响应中的 `thresholds` 数组元素，与指标一一对应（通过 `remark` 区分指标）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 配置行主键 |
| site | String | 站点档案主键（前端一般不直接用） |
| device | String | 设备 ID（站级配置时为空字符串 `""`；设备级配置可能多行，前端按 device 区分） |
| type | String | 类型编码（`#8#` 水质；多类型用 `|` 分隔，前端按含 `#8#` 过滤） |
| remark | String | 指标描述（如"氨氮""COD"），同一站点一行一个指标 |
| threshold | Number | 警戒值 |
| guarantee | Number | 保证值 |
| num | Number | 预警比对值（可为 `null`） |

- 阈值行的三个数值用于：①趋势图按指标画预警线；②营养盐占比图的"限值"分母与 100% 参考线
- 前端绘制预警线时按指标（remark）从 thresholds 中取对应行；同一指标存在设备级多行时取站级行（device 为空）或按需处理
- 阈值仅作**展示参考线**，超标并不产生告警/提示接口——页面如需超标提示，由前端按行内数值自行比对

---

## 6. 数值语义速查（页面展示规则）

| 值 | 含义 | 展示建议 |
|---|---|---|
| `0` | 低于检出限（如 COD=0.0），属正常 | 正常展示 0 |
| `null` | 无数据（bod5 恒为 null；某字段设备未上报） | `--` / 图表断线 |
| `-9991` | 设备通讯异常 | `--`（列表与历史明细出现时） |
| `-999` | 设备不存在 | 后端已转 `null`，不会出现 |

---

## 7. 常见问题

| 现象 | 原因与处理 |
|---|---|
| 站点下拉为空 / 列表空 | 该站尚无水质数据上报（数据驱动），等待设备报文后自动出现；前端正常渲染空态即可 |
| 趋势图全是 null 断线 | 该时段设备未上报或值异常被剔除（趋势仅对正常值取均值），不补 0 |
| bod5 恒为 null | 五日生化需氧量为实验室指标、设备不上报；后续上游回填后自动有值，无需前端改造 |
| 监测时间为空 | 拆表迁移期的历史脏数据；新上报数据恒有监测时间（见 3.1 `tm`） |
| 请求返回 401 | 会话失效/未登录，重新登录后携带 `X-Session-Id` 重试 |
| 请求返回 400 | 参数非法（时间格式错误等），按本文档格式修正 |
