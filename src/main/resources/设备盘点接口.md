# 设备盘点接口

设备盘点按「盘点单」办理：**一张主表 + 明细（物资 × 盘点仓库）+ 附件**，保存即生效（不提供删除），
编辑仅限盘点人/备注/附件（不触碰台账、明细与流水）。
一次保存联动四件事：盘点单主/明细留痕 → 逐行**账面一致性校验**（页面快照 vs 台账实时值，
不一致整单拒绝） → 台账**绝对校正**（`tzkioe` 库存数 = 实盘） → 差异行写盘盈/盘亏流水。

- 页面：`/inventory-stocktake.html`（P6 盘点单列表 + P7 新增/查看/编辑抽屉 + 选择物资弹窗）；单文件页面
- 与出入库**同底座**：共用物资目录 `t_auto_hltgq_knc3g_slaifi`、台账 `t_auto_hltgq_knc3g_tzkioe`、
  编号序列 `t_auto_hltgq_water_order_no_seq`（serial_type=`PDD`）、流水 `t_auto_hltgq_water_stock_change_log`
- 本期新建 3 张表（`"qixiao-apaas"`）：
  `t_auto_hltgq_water_stocktake_order`（盘点单主表）、
  `t_auto_hltgq_water_stocktake_order_detail`（明细）、
  `t_auto_hltgq_water_stocktake_attachment`（附件）
- 盘点单号：**PDD + yyyyMMdd + 4 位序号**（如 `PDD202610120001`）；取号走独立事务（REQUIRES_NEW），
  并发/失败场景**跳号属预期**（不重号即可）
- 权限：**本期所有登录用户可用**（与出入库同口径）；后续收紧为指定角色时在 `/inventory-stocktake`
  加角色断言即可（已留扩展点）

## 1. 字段口径

### 1.1 列表行（P6，`StocktakePageItemVO`）

| 字段 | 含义 |
|---|---|
| `id` / `orderNo` | 盘点单 ID（详情入参）/ 单号（PDD 前缀，全局唯一） |
| `checkDate` | 盘点日期 `yyyy-MM-dd` |
| `warehouseId` / `warehouseName` | 盘点仓库 |
| `operatorId` / `operatorName` | 盘点人（姓名快照，编辑可改） |
| `remark` | 备注（≤50 字，可空） |
| `createdAt` | 创建时间 `yyyy-MM-dd HH:mm:ss` |
| `attachments` | 附件摘要数组（`id`/`fileName`/`fileSize`/`fileExt`），由后端分页后批量装配 |

排序：盘点日期倒序 → 创建时间倒序 → 单号倒序。

### 1.2 详情（`StocktakeDetailVO`，`/detail` 返回）

主表字段同 §1.1（减 `attachments`），另含：

- `items[]`（`StocktakeItemVO`）：`materialId` / `materialCode` / `materialName` / `materialBrand` /
  `materialSpec` / `materialUnit`（**物资快照，固化于盘点单**）、`bookQty`（账面快照，一致性校验基准）、
  `checkQty`（实盘，≥0）、`profitQty`（盘盈 = check−book，>0 时）/ `lossQty`（盘亏 = book−check，>0 时）；
  排序按录入顺序（`created_at ASC`）；
- `attachments[]`：`id` / `orderId` / `fileName` / `fileSize` / `fileExt`（`filePath` 为内部字段，对外不返回）。

## 2. 字典

### 2.1 盘点单号

`PDD` + `yyyyMMdd` + 4 位序号（与 RK/CK 共用序列表 `water_order_no_seq`，`serial_type=PDD`）。

### 2.2 流水字典（盘点产生项）

- `change_type`：`#3#` 盘盈 / `#4#` 盘亏（**仅差异行**写流水；`qty_before` = 账面、`qty_after` = 实盘、`change_qty` = 差异绝对值）
- `order_kind`：`#3#` 盘点单；`biz_type` 快照恒 `#3#`
- 无差异的行**不写流水**（大盘点不会刷屏流水页）

### 2.3 del_flag

`#2#` 正常（本期不提供删除，恒 `#2#`；编辑不改变）。

## 3. 接口契约

统一前缀 `/inventory-stocktake`；**生产环境统一加 `/hltgq-site` 前缀**，需登录会话。
业务校验失败返回 **HTTP 400 + `{message}`**（`GlobalExceptionHandler` 统一处理），前端 toast `message` 即可；
台账更新失败等状态冲突返回 502 + `{message}`（罕见，重试即可）。

### 3.1 接口清单

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/inventory-stocktake/meta` | 表单元数据：`warehouses[]`（**仅启用**）+ `today` + `currentUser{id,name}` |
| GET | `/inventory-stocktake/page` | 列表分页（9 参数见下；排序见 §1.1） |
| GET | `/inventory-stocktake/detail?id=` | 详情（主表 + 明细 + 附件） |
| POST | `/inventory-stocktake/save` | 新增盘点单（保存即生效）→ 返回保存后详情 |
| POST | `/inventory-stocktake/update` | 编辑（仅盘点人/备注/附件）→ 返回编辑后详情 |
| GET | `/inventory-stocktake/stock-ledgers?warehouseId=&keyword=` | 带出：当前仓库台账**全量行（含 0 库存）**；`quantity` = 账面；返回上限 **501 行 = 明细上限 500 + 1 行截断探测**（超限由前端截断至 500 行并提示分批另建） |
| GET | `/inventory-stocktake/material-options?warehouseId=&keyword=` | 手动加行：物资目录全量 + 该仓库实时账面（无台账记 0，含纯盘盈场景） |
| POST | `/inventory-stocktake/attachment/upload` | 附件上传（multipart `file`；白名单 + 单文件 ≤20MB）→ `{id,fileName,fileSize,fileExt}` |
| GET | `/inventory-stocktake/attachment/download?id=` | 附件下载（`Content-Disposition` 带原始文件名；前端 fetch + blob） |
| POST | `/inventory-stocktake/attachment/remove?id=` | 附件移除（**仅限未绑定盘点单的新上传附件**：新增取消清理 / 编辑态移除新上传；物理删文件 + 删行） |

盘点人候选复用 `GET /inventory-order/users`（`value`/`label`/`sub`，与出入库经办人同源）。

**`/page` 参数（9 个）**

| 参数 | 说明 |
|---|---|
| `page` / `size` | 默认 `1` / `20`；size 上限 100，page 上限 100000（与出入库同口径） |
| `orderNo` | 盘点单号模糊 |
| `warehouseId` | 盘点仓库精确匹配 |
| `operatorId` | 盘点人精确匹配 |
| `materialCode` / `materialName` | **明细级**模糊（单含任一匹配明细即命中） |
| `startDate` / `endDate` | 盘点日期闭区间 `yyyy-MM-dd`；格式非法 400 |

返回：`{total, page, size, pages, records:[§1.1 列表行]}`。

### 3.2 POST `/save` 提交体

```json
{
  "checkDate": "2026-10-12",
  "warehouseId": "...",
  "operatorId": "...",
  "remark": null,
  "items": [{"materialId": "...", "bookQty": 8, "checkQty": 6}],
  "attachmentIds": ["..."]
}
```

- 物资快照（编号/名称/品牌/规格/单位）**不接受前端传入**，后端按 `materialId` 回查目录固化，防篡改；
- `bookQty` 为页面带出/加行时的账面快照（后端以台账**实时值**校验，不是提交值说了算）；
- `attachmentIds` 为本次提交的附件 ID 列表（上传时未关联，保存时回填归属；已被其它单占用一律拒绝）。

### 3.3 POST `/update` 提交体

```json
{"id": "...", "operatorId": "...", "remark": null, "attachmentIds": ["..."]}
```

- `attachmentIds` 为编辑后**最终保留**的附件集合；不在集合内的本单附件将被物理移除；
- 编辑**不触碰台账、明细与流水**（历史流水经手人不变；盘点人姓名快照同步更新）。

### 3.4 保存事务（先后次序）

1. 校验（日期 / 仓库启用 / 盘点人 / 备注 ≤50 字 / 明细非空且 ≤500 行、物资存在不重复、账面与实盘非负整数）；
2. 取号（独立事务 `PDD`）→ 写主表 → 逐行：
   台账 `FOR UPDATE` 锁行重读 → 与页面快照比对（不一致**整单拒绝**，不允许强制覆盖）→
   绝对校正（`ejgxlq` = 实盘；无台账行自动建账 = 纯盘盈）→ 写明细 → 差异行写流水（`#3#`/`#4#`）；
3. 附件回填归属；**任一步失败整体回滚**（编号不回滚，跳号属预期）。

## 4. 校验规则（后端 message 与前端行为对照）

| 情况 | 后端行为 | 前端行为 |
|---|---|---|
| 请求体为空 | 400「请求体不能为空」 | — |
| 日期未选 / 格式错 | 400「请选择盘点日期」/「盘点日期格式应为 yyyy-MM-dd：xxx」 | 默认当天可改；未选标红拦截 |
| 仓库未选 / 不存在 / 已停用 | 400「请选择盘点仓库」/「仓库不存在或已删除」/「仓库已停用，不可选择」 | 下拉只列启用仓库（meta）；未选标红拦截 |
| 盘点人未选 / 不存在 | 400「请选择盘点人员」/「盘点人不存在或已删除」 | 默认当前登录人可改；未选标红拦截 |
| 备注超 50 字 | 400「备注不能超过 50 字」 | `maxlength=50` + 字数统计 |
| 明细为空 / 超 500 行 | 400「请至少添加一行盘点明细」/「明细行数不能超过 500 行」 | 拦截提示同文案 |
| 物资为空 / 不存在 / 重复 | 400「第 N 行：请选择物资」/「第 N 行：物资不存在或已删除」/「第 N 行：物资重复，同一物资只能出现一行」 | 弹窗已添加行置灰防重 |
| 账面/实盘非法 | 400「第 N 行：账面库存必须为不小于 0 的整数」/「第 N 行：实盘数量必须为不小于 0 的整数」 | 行内输入过滤 + 保存前校验拦截 |
| **账面快照与台账不一致** | 400「第 N 行「名称」：账面库存已发生变化（当前 X，页面为 Y），请关闭弹窗重新盘点后再保存」（整单拒绝） | toast；抽屉不关、已填内容与附件保留 |
| 台账更新失败（罕见） | 502「台账更新失败，请重试」（整单回滚） | toast，重试即可 |
| 附件类型不支持 | 400「不支持的文件类型（仅支持图片、PDF、Word、Excel）：xxx」 | 选择文件后本地预检拦截 |
| 附件超 20MB | 400（multipart 限制） | 本地预检拦截（单文件 20MB） |
| 附件不存在 / 被其它单占用 | 400「附件不存在或已移除」/「附件已被其他盘点单占用：xxx」 | toast（正常流程不会产生） |
| 移除已绑定附件（直接调 remove） | 400「附件已保存到盘点单，不能直接移除」 | 正常流程不会产生；已绑定附件的删除只经编辑保存（保留集合差集）执行 |
| 单号取号失败（罕见） | 502「单据编号生成失败，请重试」 | toast，重试即可 |

## 5. 页面说明

### 5.1 P6 盘点单列表（`/inventory-stocktake.html`）

- **筛选**：常显 3 项（盘点单号、仓库）+「更多条件」展开 4 项（盘点人、物资编码、物资名称、盘点日期起止闭区间）；
  下拉选中不即查，统一「查询」按钮提交；「重置」清空条件并回到第 1 页；
- **列表 8 列**：盘点单号（蓝字可点击打开详情）/ 盘点日期 / 仓库 / 盘点人 / 备注 / 附件（文件名可点击下载，
  超 2 个折叠为 +N）/ 创建时间 / 操作（查看、编辑）；
- 工具栏「新增盘点单」；分页支持每页条数与跳页。

### 5.2 P7 新增 / 查看 / 编辑（抽屉）

- **新增**：单号只读（「系统按 PDD+日期+4位序号 自动生成」）；盘点日期默认当天可改；盘点人默认当前登录人可改；
  备注 50 字计数；
- **明细两种录入**：「带出当前仓库台账」（全量含 0，实盘默认 = 账面，需逐行核对；**超 500 行自动截断**，
  提示「剩余物资请保存后另建盘点单」）或
  「手动加行」（物资目录全量 + 该仓库实时账面多选弹窗，已添加行置灰；勾选后总量超 500 行拦截）；
- **行内实时提示**：实盘 ≠ 账面即时显示「盘盈 +N」（绿）/「盘亏 -N」（红），相等显示「持平」；
  数量输入仅允许非负整数（最多 9 位）；行可删除、「清空明细」（二次确认）；
- **附件**：上传（图片/PDF/Word/Excel，单文件 ≤20MB）/ 点击文件名下载 / 移除；
  新增取消时未提交的附件自动清理（保存成功路径不清理）；**保存请求进行中冻结关闭 / 上传 / 带出 /
  加行 / 清空 / 附件移除入口**（防附件清理与保存提交竞态）；上传完成时抽屉已关闭的孤儿附件即时清理；
- **保存成功**：toast「保存成功」→ 关闭抽屉 → 回列表第 1 页 → 新单行高亮；
- **查看**：两列键值 + 明细只读表（盘盈 +N 绿标 / 盘亏 -N 红标）+ 附件列表；
- **编辑**：日期 / 仓库 / 明细只读；盘点人 / 备注 / 附件可改（移除已绑定附件在保存后生效）。

### 5.3 P5 流水联动（`/inventory-ledger.html`）

盘盈 / 盘亏流水进入 P5「出入库记录」弹窗，类型标签：**盘盈 = 绿 / 盘亏 = 红**
（入库 = 蓝 / 出库 = 橙黄）。

## 6. 注意事项（对外约定）

1. **保存即生效**：盘点无编辑明细与删除接口（设计方案口径）；纠错靠重新盘点，后续如需冲正另行设计；
2. **账面一致性强制**：保存时逐行与台账实时值比对，不一致**整单拒绝**（不允许「强制覆盖」）；
   多人在库操作时以「页面快照 = 台账实时值」为准，冲突提示后需关闭弹窗重新盘点；
3. **台账绝对校正**：保存后该「物资 × 仓库」台账库存 = 实盘值；仅差异行写盘盈/盘亏流水；
   无台账行的纯盘盈自动建账（初始量 = 实盘，安全库存取目录文本解析，可空）；
   无台账且实盘为 0 不建账（避免产生空台账行，无校正与流水）；
4. **编号跳号属预期**：取号独立事务，并发或保存失败会跳号；只保证不重号、不保证连续；
5. **编辑边界**：仅盘点人 / 备注 / 附件；明细、台账与历史流水永不因编辑变化；
6. **附件存储**：本地 `file-dir`（容器挂载 `/app/file-dir`），相对路径 `stocktake/yyyy-MM/uuid_原名`；
   移除即物理删文件（best-effort）+ 删行；下载前做目录穿越校验；`deploy.sh` 已含目录创建与挂载；
   `remove` 接口仅接受**未绑定**附件（已绑定附件的删除只经编辑保存的「保留集合差集」执行）；
7. **权限**：本期与出入库同口径（登录即可用）；角色收紧是后续扩展点，接口契约不变；
8. **全局上传大小放宽**：`spring.servlet.multipart` 全局 20MB/25MB（application.properties 有注记），
   惠及既有上传接口（巡检/水位/预测/分配等），仅放宽大小上限、不改变各自白名单与业务校验。
