# 三方接入接口文档（三维 / 档案系统单点登录）

> 本文档供**前端开发**对接使用：生产环境路径统一加 `/hltgq-site` 前缀
> 本模块实现：平台登录态 → 三维系统 token / 档案系统 token+userId（单点登录），前端持凭证跳转对应系统
> 完成状态：均已联调验证通过（`auth.enabled=true` 全量鉴权已开启）

## 模块总览

| 接口 | 方法 | 用途 | 前端场景 |
|------|------|------|---------|
| `/auth/3d-token` | POST | 获取三维系统 token | 单点登录跳转三维系统 |
| `/auth/archive-token` | POST | 获取档案系统 token + userId | 单点登录跳转档案系统 |
| `/auth/current-user` | GET | 当前登录人 | 获取登录人信息（通用接口，多处复用） |

---

## 〇、公共约定

### 0.1 基础信息

- **生产 Base URL**：`http://220.179.1.110:8081/hltgq-site/auth/...`（本地联调去掉 `/hltgq-site` 前缀）
- **认证方式**：本项目**不负责登录**，用户须先登录平台。同域访问（nginx 代理）时浏览器**自动携带 Cookie `sessionId`**，前端无需任何处理；服务端代理场景可通过 Header `X-Session-Id` 传递会话
- **三维 token 缓存**：后端按登录人缓存 30 分钟（短于三维 JWT 有效期），缓存期内重复调用返回同一 token，开销极低
- **登录验证**：本项目所有接口已启用登录验证，未登录的 AJAX 请求返回 401，页面导航 302 跳平台登录页（见第四节）

### 0.2 错误约定

| HTTP 状态 | 响应体 | 场景 | 前端处理 |
|----------|--------|------|---------|
| 401 | `{"code":401,"message":"未登录","redirectUrl":"http://220.179.1.110:8081/login/user/login"}` | 未登录 / 会话过期 | 引导跳转 `redirectUrl`（平台登录页） |
| 302 | 跳转平台登录页 | 未登录（页面直接导航） | 浏览器自动处理，无需前端干预 |
| 502 | `{"code":502,"message":"..."}` | 三维 ssoLogin / 档案系统（浩微）接口调用失败、超时、返回异常码 | 提示用户稍后重试 |
| 503 | `{"code":503,"message":"会话服务不可用，请稍后重试"}` | Redis 会话服务故障 | 提示用户稍后重试 |

## 一、获取三维系统 token（POST /auth/3d-token）

### 1.1 请求

```
POST /auth/3d-token
```

- 无请求参数、无 body，会话由 Cookie `sessionId`（或 Header `X-Session-Id`）自动携带

### 1.2 响应

**正常响应**（200，生产实测）：

```json
{
  "token": "eyJhbGciOiJIUzUxMiJ9.eyJleHAiOjE3ODgwMTMyMDAsImxvZ2luX3VzZXJfa2V5IjoiOTdjODdkNjktNmNjMy00YTJiLTg4ZDctNjZmYjA4ZGU0ZWJkIn0.BzfFF2R7r-31svXjhNSeddUmxsfEcug7YXQ2I-xMZ90se6II-i5gqC37CWx-uNsOhCpgsLl6FKI5IPhmvVp_BQ"
}
```

### 1.3 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| token | String | 三维系统 JWT token，用于拼接三维系统单点登录地址 |

### 1.4 前端要点

1. 调用 `POST /auth/3d-token` 获取 token
2. 拼接三维系统地址（hash 路由携带 token）：`http://220.179.1.110:8012/#/overview?token={token}`
3. 跳转（建议新窗口打开）：

```js
// 示例：单点登录跳转三维系统
fetch('/hltgq-site/auth/3d-token', { method: 'POST' })
  .then(r => {
    if (r.status === 401) {
      const p = r.json().then(d => window.location.href = d.redirectUrl);
      return p;
    }
    if (!r.ok) throw new Error('获取三维 token 失败，请稍后重试');
    return r.json();
  })
  .then(d => {
    if (d && d.token) {
      window.open('http://220.179.1.110:8012/#/overview?token=' + d.token, '_blank');
    }
  });
```

## 二、当前登录人（GET /auth/current-user）

### 2.1 请求

```
GET /auth/current-user
```

- 无请求参数，会话由 Cookie `sessionId`（或 Header `X-Session-Id`）自动携带

### 2.2 响应

**正常响应**（200，生产实测）：

```json
{
  "userId": "VDLqdrLqoRQkmH7tltL",
  "corpCode": "hltgq",
  "superAdmin": "true",
  "loginName": "18956011517"
}
```

### 2.3 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| userId | String | 用户主键（`t_apaas_uc_user.id`） |
| corpCode | String | 企业编码（当前系统恒为 `hltgq`） |
| superAdmin | String | 是否超级管理员（`"true"`/`"false"`，可用于前端权限判断） |
| loginName | String | 登录名（三维系统 ssoLogin 的用户名，当前为手机号） |

### 2.4 前端要点

- 通用「当前登录人」接口，后续各业务模块需要登录人信息时统一复用，无需重复实现
- `loginName` 由后端按 `userId` 查库获得（本地缓存 5 分钟），前端直接使用即可

## 三、获取档案系统 token + userId（POST /auth/archive-token）

### 3.1 请求

```
POST /auth/archive-token
```

- 无请求参数、无 body，会话由 Cookie `sessionId`（或 Header `X-Session-Id`）自动携带

### 3.2 响应

**正常响应**（200，生产实测）：

```json
{
  "token": "35aa2b593521e92d2e18015c68ed1441094144ec05939290",
  "userId": "d2a73c9004f94d1895dc041f32124848"
}
```

### 3.3 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| token | String | 浩微档案系统 token，**5 分钟有效**，须立即用于跳转（后端缓存 270 秒，缓存期内重复调用返回同一 token） |
| userId | String | 浩微档案系统用户 ID；后端**保证一定返回**（已同步用户直接读库，未同步用户自动实时同步后返回） |

### 3.4 前端要点

1. 调用 `POST /auth/archive-token` 获取 token + userId
2. 拼接档案系统地址（两个参数都必传）：`http://172.27.177.30:8090/archive/index/index?UserID={userId}&token={token}`
3. 跳转（建议新窗口打开）：

```js
// 示例：单点登录跳转档案系统
fetch('/hltgq-site/auth/archive-token', { method: 'POST' })
  .then(r => {
    if (r.status === 401) {
      return r.json().then(d => window.location.href = d.redirectUrl);
    }
    if (!r.ok) throw new Error('获取档案系统凭证失败，请稍后重试');
    return r.json();
  })
  .then(d => {
    if (d && d.token && d.userId) {
      window.open('http://172.27.177.30:8090/archive/index/index?UserID=' + d.userId + '&token=' + d.token, '_blank');
    }
  });
```

### 3.5 后端兜底说明（前端无需处理）

- 人员同步成功后，后端自动将浩微 userId 回写企效用户表，SSO 接口直接读库返回
- 若该用户从未同步（读库无 userId），后端自动对该用户实时同步一次档案系统再返回，本次请求耗时增加约 1~2 秒
- 用户无部门等异常场景返回 502，前端按错误约定提示重试

## 四、三维系统单点登录完整流程

```
┌─────────────┐   已登录（Cookie sessionId）   ┌──────────────────┐
│   平台登录    │ ─────────────────────────────▶ │ 本项目 /auth/* 接口 │
└─────────────┘   nginx 同域代理，自动携带 Cookie  └────────┬─────────┘
                                                        │ ① 后端：sessionId → Redis 会话 → userId
                                                        │ ② 后端：userId → 查库 login_name
                                                        │ ③ 后端：login_name → 三维 ssoLogin → token
                                                        ▼
                                          POST /auth/3d-token 返回 {"token":"..."}
                                                        │
                                                        │ ④ 前端：拼接待跳转地址
                                                        ▼
                                http://220.179.1.110:8012/#/overview?token={token}
```

前端仅需两步：

1. 调 `POST /auth/3d-token` 拿 token（未登录时收到 401，跳 `redirectUrl` 回平台登录）
2. 打开 `http://220.179.1.110:8012/#/overview?token={token}` 完成三维系统单点登录

## 五、登录验证拦截说明（供联调参考）

- **拦截范围**：本项目所有接口已启用登录验证；无会话的 AJAX 请求返回 401 JSON（含 `redirectUrl`），浏览器页面导航返回 302 跳平台登录页
- **白名单放行**：静态页面（`*.html`、`/lib/**`、`/templates/**`）、`/error`、`/auth/login`、`/archive/sync/trigger`（档案手动同步触发接口，自带 X-API-Key 鉴权，前端不用）无需登录
- **会话服务故障**：Redis 不可达时返回 503，**不做降级放行**（安全取舍）
- **三维接口故障**：ssoLogin 调用失败返回 502，不影响本系统其他功能
- **档案接口故障**：浩微接口调用失败返回 502，不影响本系统其他功能（定时同步失败仅记日志，下次自动重发）
