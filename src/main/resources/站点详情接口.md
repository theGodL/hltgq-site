# 站点详情接口

> 适用范围：站点详情页（`station-detail.html`：基础信息 / 巡检记录 / 问题记录 / 维修工单记录 / 设备信息五个页签）后端数据服务。
>
> 接口均为实时查询（无缓存、无轮询任务），走现有登录会话鉴权；参数越界（分页非法、站点不存在等）统一报 400。
> 契约字段命名与页面原型对齐，前端零改动接入；翻译字段返回权威名称（业务标准文案），`*Code` 字段为原始编码（权威值，供前端自定义展示/排查）。

---

## 通用约定

| 约定 | 说明 |
|------|------|
| 鉴权 | 全部接口需登录会话（与站内其他接口一致） |
| 站点键 | 各接口 `stationId` 必填，**双键兼容**：站点档案表主键 `id`（监测/业务表 `site` 值，如 `CAYQ739MiBWMg9gQvyi`）或站点编号（档案表 `iofhpi`，如 `QSJSZ`、`NSS`）；均不支持按站点名称查询。站点不存在报 400 |
| null 语义 | 无数据返回 `null`，**不返回 0**（0 = 真实值为 0）；空列表返回 `[]` |
| 时间格式 | 参数：日期 `yyyy-MM-dd`；响应时间戳为 ISO `yyyy-MM-dd'T'HH:mm:ss`（Jackson 默认序列化，前端自行格式化展示） |
| 分页结构 | 分页接口返回 MyBatis-Plus Page 结构：`records`（行数组）、`total`（总条数）、`size`、`current`、`pages`；`page` 从 1 起，`size` 上限 1000，非法报 400 |
| 编码字典 | 巡检结果 `#1#` 待填写 `#2#` 正常 `#3#` 异常 `#4#` 隐患 `#5#` 缺陷 `#6#` 故障；巡检状态 `#1#` 草稿 `#2#` 已提交；问题处理方式 `#1#` 待确认 `#2#` 转工单 `#3#` 直接处理；问题状态 `#1#` 待处理 `#2#` 处理中 `#3#` 已转工单 `#4#` 已关闭 `#5#` 已作废；类型 `#1#` 水位 `#2#` 雨量 `#3#` 流量 `#4#` 闸门 `#5#` 视频 `#7#` 墒情 `#8#` 水质（多值 `\|` 分隔）；在线状态 `#1#` 在线 `#2#` 离线 |
| 异常值 | 监测数据 -999（设备不存在）/ -9991（设备异常）一律过滤为 null，不返回前端 |

---

## 接口总览

| 序号 | 接口 | 说明 |
|:--:|------|------|
| 一 | GET `/station-detail/basic` | 基础信息聚合（档案 + 闸口数 + 供电/网络 + 视频通道） |
| 二 | GET `/station-detail/patrol/page` | 巡检记录分页（时间/人员/结果/是否发现问题筛选） |
| 三 | GET `/station-detail/patrol/{recordId}` | 巡检记录详情（查看弹窗，含关联问题） |
| 四 | GET `/station-detail/issue/page` | 问题记录分页（时间/发现人/处理方式/状态筛选） |
| 五 | GET `/station-detail/order/page` | 维修工单记录分页 |
| 六 | GET `/station-detail/device/page` | 设备信息分页（编号/名称/类型/状态筛选 + 实时数据） |
| 七 | GET `/station-detail/options` | 筛选下拉选项（巡检人员/发现人/设备名称） |

## 二、巡检记录分页

```
GET /station-detail/patrol/page?stationId=xxx&date=2026-08-11&person=李明&result=异常&hasIssue=1&page=1&size=10
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| stationId | String | 是 | 站点键 |
| date | String | 否 | 巡检日期 `yyyy-MM-dd`（命中当日 [00:00, 次日 00:00)） |
| person | String | 否 | 巡检人员姓名模糊匹配 |
| result | String | 否 | 巡检结果：`正常`（仅 #2#）或 `异常`（含隐患/缺陷/故障档 #3#~#6#）；不传=全部 |
| hasIssue | String | 否 | 是否发现问题：`1` 是（有关联问题或异常档）/ `0` 否；不传=全部 |
| page / size | Number | 否 | 页码（默认 1）/ 每页条数（默认 10，上限 1000） |

响应（分页壳省略 `size`/`current`/`pages`）：

```json
{
  "records": [
    {
      "code": "巡检记录主键id",
      "time": "2026-08-11T09:30:00",
      "person": "李明",
      "object": "1号闸门、闸站控制柜",
      "deviceIds": "原始device多选串",
      "content": "控制柜散热风扇异常，柜内温度偏高，已现场记录并关联问题。",
      "result": "异常",
      "resultCode": "#3#",
      "hasIssue": true,
      "relatedIssue": "配电柜温度偏高、散热风扇异响",
      "status": "已提交",
      "statusCode": "#2#"
    }
  ],
  "total": 3
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 记录编号（巡检记录主键 id，业务表无 code 字段） |
| time | String | 巡检时间（ISO） |
| person | String | 巡检人员姓名（JOIN 平台用户表 name，用户被删时为 null） |
| object | String | 巡检对象（巡检记录 device 多选解析出的设备名「、」拼接） |
| deviceIds | String | 巡检对象原始串（device 列原文，权威值，供前端自定义展示/排查） |
| content | String | 巡检说明（content） |
| result / resultCode | String | 巡检结果翻译 / 编码原文（6 档） |
| hasIssue | Boolean | 是否发现问题（派生：存在关联问题记录 或 result 为异常档） |
| relatedIssue | String | 关联问题标题「、」拼接（问题表 abqezf = 本记录 id，无则 null） |
| status / statusCode | String | 状态翻译（草稿/已提交）/ 编码原文 |

## 六、设备信息分页

```
GET /station-detail/device/page?stationId=xxx&code=SB-0005&name=1号闸门&type=闸门&status=在线&page=1&size=10
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| stationId | String | 是 | 站点键 |
| code | String | 否 | 设备编号模糊匹配 |
| name | String | 否 | 设备名称精确匹配（配合 `/options` 下拉使用） |
| type | String | 否 | 设备类型：`闸门`（→ #4#）或监测类型数字 `1/2/3/4/5/7/8`；页面其他分类（启闭/监测/电气设备）表内无对应编码，不传=全部 |
| status | String | 否 | 设备状态：`在线`（#1#）/ `离线`（#2#）（权威文案，与响应翻译一致，兼容旧词「正常/关闭」）；不传=全部 |
| page / size | Number | 否 | 同巡检分页 |

响应：

```json
{
  "records": [
    {
      "id": "设备主键id",
      "code": "SB-000501",
      "name": "南山寺节制闸1#",
      "type": "闸门",
      "typeCodes": "#4#",
      "gate": "1",
      "status": "在线",
      "statusCode": "#1#",
      "metric": "当前开度",
      "value": 1.20,
      "textValue": null,
      "unit": "m"
    }
  ],
  "total": 6
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | String | 设备主键（设备表 id） |
| code | String | 设备编码（如 `1000231$1$0$10`） |
| name | String | 设备名称（如「南山寺节制闸1#」） |
| type / typeCodes | String | 设备类型翻译 / 编码原文（type，多值 `\|` 分隔） |
| gate | String | 所属闸口（由设备名按「站点名+闸孔号#」规则解析，如「1」；无闸孔信息为 null） |
| status / statusCode | String | 设备状态翻译（在线/离线）/ 编码原文 |
| metric | String | 实时数据指标名（如 当前开度/当前水位/日累计雨量/瞬时流量/10cm含水率/氨氮；无实时数据为 null） |
| value | Number | 实时数据数值（BigDecimal 保留尾零，如 1.20；-999/-9991 已过滤为 null） |
| textValue | String | 实时数据文本值（**恒 null**：视频巡检结果数据在 device 服务，本地库无数据源） |
| unit | String | 实时数据单位（m / mm / m³/s / % / mg/L；无数据为 null） |

**实时数据取数口径（站点级）**：各监测表与设备表无 device 外键，按站点键关联取最新一条：闸门按设备名解析闸孔号匹配闸门表 site+gate_no 最新开度（排除站级占位行 gate_no='0'）；水位按 STCD=iofhpi 查水位表最新 Z；雨量按 STCD=iofhpi 查雨量表最新 DRP（水文日累计）；流量按 site 查流量表最新 q；墒情按 stcd/site 查墒情表最新 mten；水质按 stcd/site 查水质表 nmisp_info 最新 nh3n；视频设备无巡检结果数据，textValue 恒 null。数值精度与各监测页口径一致（SQL TRUNC）：闸门开度/水位/雨量/墒情 2 位，流量/氨氮 3 位。

## 附录：数据源与口径

| 数据 | 表 | 关联口径 |
|------|------|------|
| 站点档案 | `t_auto_hltgq_5nw74_vnqqef` | id=主键、iofhpi=站点编号（即水文表 STCD）、zzkaec=名称、epjutj=类型、bviiio_x/y=经纬度、zebpsu=在线状态、waljdn=是否接通市电、bhsqxd=传输方法 |
| 供电 | `t_auto_hltgq_water_vol_info` | site=档案 id，取最新一行：vol 电压、tm 时间（电流/信号列库中未确认，不取） |
| 闸口数/视频通道 | `t_auto_hltgq_water_device` | site=档案 id；type LIKE '%#4#%' 计数；type LIKE '%#5#%' 为视频通道 |
| 巡检记录 | `t_auto_hltgq_water_inspection_record` | site=档案 id；user→平台用户表 name；patrol_schedule→巡检计划 title；device 多选原文返回 deviceIds 并由后端解析设备名 |
| 巡检计划 | `t_auto_hltgq_water_patrol_schedule` | id=主键、title=计划名称 |
