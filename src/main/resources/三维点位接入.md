# 三维点位接入（监测点位 + 经纬度）

> 适用范围：三维系统监测点位接入——点位打点（三维场景标点）+ 点位实时值展示。
>
> 覆盖五类监测接口（均为站内监测页面在用接口，**直接复用、无需另行开发**）：**水位 / 闸门、雨量、流量、墒情、水质**。各接口响应均含站点经纬度 `lon` / `lat`，可直接作为三维打点坐标。
>
> **本次接入改造（2026-09）**：
> 1. 五类接口响应新增站点经纬度 `lon` / `lat`（三维打点直接使用）；
> 2. 新增可选 `canalId` 渠系树过滤参数（按渠系 / 区域取点位，返回该渠系及**全部子孙渠系**下的点位）；
> 3. 老站点（档案未直接关联）按测站编号 `stcd` 补位匹配站点档案——经纬度与渠系信息同样可取。
>
> **接入范围提示（三维前端当前预期，非接口限制）**：水位场景预计**仅接入水库相关点位**；流量点位预计**暂不需要**。本文档仍将五类接口的**全量调用细节（入参 / 响应 / 字段）**完整给出——接口默认返回全量点位，实际接入哪些点位由三维前端按需选取（可按站点名称、渠系 `canalId` 或站点编号筛选）。
>
> 关联文档：通用约定（鉴权 / 环境 / null 语义等）与《三维系统对接接口.md》一致；页面全量字段字典见《灌区接口文档.md》，本文档与其同源同步维护。

## 通用约定（对接方必读）

| 约定 | 说明 |
|------|------|
| 环境 | 生产访问前缀 `http://220.179.1.110:8081/hltgq-site`；正文各处均省略该前缀。完整 URL 示例：`http://220.179.1.110:8081/hltgq-site/gate-monitor/monitoring` |
| 鉴权 | 所有数据接口需携带登录会话：请求头 `Authorization: <sessionId>`（或 `X-Session-Id`；Cookie `sessionId` 亦可）。会话获取 `POST /auth/login`（key / secret 线下提供），详见《三维系统对接接口.md》「通用约定」 |
| 时间格式 | 请求参数：日期 `yyyy-MM-dd`、时间戳 `yyyy-MM-dd HH:mm:ss`（URL 中空格写 `+` 或 `%20`）；响应时间戳统一 ISO `yyyy-MM-dd'T'HH:mm:ss` |
| null 语义 | 无数据字段返回 `null`，**不返回 0**（0 = 真实值为 0）；对接方按 `null` 处理缺数 |
| 精度 | 页面同源输出（库值直出、保留小数尾零），精度以返回值为准；经纬度为站点档案原值 |

| 刷新频率 | 五接口均为实时查询（无缓存），三维侧按 60s 间隔刷新即可 |
| 样例说明 | 「响应示例」为字段结构样例：闸门 / 雨量 / 流量示例取自 2026-09-08 现网实测素材、墒情 / 水质为结构样例；数值形态与线上一致，站点与数值会随时间变化，对接以实际返回为准 |

## 点位总览

| 类型 | 接口 | 方式 | 点位主键 | 经纬度 | 在线状态 | 主要实时值 | 三维接入预期 |
|------|------|:--:|------|:--:|:--:|------|------|
| 水位 / 闸门 | `/gate-monitor/monitoring` | GET | `siteId` | `lon` / `lat` | `isOnline` | 闸前 / 闸后水位、瞬时 / 累计流量、闸孔开度 | 预计仅水库相关点位 |
| 雨量 | `/st-pptn-r/gq-rainfall` | GET（分页） | `stcd` / `id` | `lon` / `lat` | `isOnline` | 当前 / 累计 / 1h / 3h / 6h / 昨日雨量 | 按需 |
| 流量 | `/flow-monitor/monitoring` | GET | `stcd` / `site` | `lon` / `lat` | — | 瞬时流量、累计流量 | 预计暂不需要（信息照全给出） |
| 墒情 | `/soil-moisture/monitoring` | GET | `stcd` / `site` | `lon` / `lat` | — | 8 个深度土壤含水量 | 按需 |
| 水质 | `/water-quality/monitoring` | GET | `stcd` / `site` | `lon` / `lat` | — | 氨氮 / COD / BOD / TP / TN / 溶解氧 | 按需 |

**点位全集获取（推荐用法）**：各 monitoring 接口**不传筛选参数 = 一次调用拿到该类型全量点位 + 各站最新实时值**（雨量接口为分页壳，站点少默认一页取全）。打点字段建议：坐标 `lon` / `lat`、名称 `siteName` / `stnm`、主键 `siteId` / `stcd` / `site`。

**辅助清单接口**（仅站点编号 + 名称，无经纬度；供筛选下拉 / 名称对照）：

```
GET /station-metrics/sites?type=gate        # 闸门/水位点位（code=siteId，name=站点名）
GET /station-metrics/sites?type=gq-rainfall # 灌区雨量点位（code=站点编号）
GET /station-metrics/sites?type=flow        # 流量点位
GET /station-metrics/sites?type=moisture    # 墒情点位
```

返回 `[{code, name, siteId?}]`（字段详见《灌区接口文档.md》第十三章）；另 `type=waterLevel` 可查水库水情站（周家河、花凉亭坝上、花凉亭坝下）编号 / 名称。

## 一、水位 / 闸门监测点位

> 点位来源：「闸门监测」页面与「水位监测」页面「花凉亭灌区」面板共用接口；每个闸站一条记录（点位 = 闸站），含闸前 / 闸后水位、闸孔开度、流量等。

### 1.1 调用细节

**请求方式**：`GET`

**请求路径**：`/gate-monitor/monitoring`

| 参数 | 必填 | 格式 | 说明 |
|------|:--:|------|------|
| site | 否 | String | 站点 UUID（= 响应 `siteId`，点位主键）；不传 = 全部闸站点位 |
| canalId | 否 | String | 渠系 id。按渠系树过滤：返回该渠系及**所有子孙渠系**下的点位（含自身）；不传则不过滤；可与 site、时间区间同传取交集 |
| startTime | 否 | `yyyy-MM-dd HH:mm:ss` | 起始时间（含）；只在此区间内取各站最新一条 |
| endTime | 否 | `yyyy-MM-dd HH:mm:ss` | 截止时间（含） |

**调用示例**：

```
GET /gate-monitor/monitoring                                     # 全量闸站点位（含经纬度与实时值）
GET /gate-monitor/monitoring?site=CAYQ739MiBWMg9gQvyi            # 单点位（渠首进水闸）
GET /gate-monitor/monitoring?canalId=7FtFhET9bThVWf3dUGI         # 按渠系取点位（含子孙渠系）
```

### 1.2 响应

数组，每个闸站一条；示例 1 条（全站约 10 个闸站）：

```json
[
  {
    "siteId": "CAYQ739MiBWMg9gQvyi",
    "siteName": "渠首进水闸",
    "canalId": "fXfNxtwluZN31ylT8UD",
    "canalName": "总干渠",
    "tm": "2026-09-08T18:00:00",
    "upZ": 42.34,
    "downZ": 42.06,
    "q": 35.683,
    "cumulativeFlow": 2869.888,
    "vol": 12.5,
    "lon": 116.2345,
    "lat": 30.5123,
    "isOnline": true,
    "holes": [
      { "gateNo": "1", "openDegree": 1.72, "status": "#1#" },
      { "gateNo": "2", "openDegree": 1.68, "status": "#1#" },
      { "gateNo": "3", "openDegree": 1.70, "status": "#1#" }
    ]
  }
]
```

**外层字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| siteId | String | 点位主键：站点 UUID（= 闸门表 `site`；闸站点位清单可通过 `/gate-monitor/sites` 获取） |
| siteName | String | 站点名称 |
| canalId | String? | 所属渠系 id；未关联渠系为 `null` |
| canalName | String? | 所属渠系名称；未关联渠系为 `null` |
| tm | String | 监测时间（ISO），取该站各闸孔中最新的时间 |
| upZ | Number? | 闸前水位（m）— 上游水位；无数据 `null` |
| downZ | Number? | 闸后水位（m）— 下游水位；无数据 `null` |
| q | Number? | 瞬时流量（m³/s）；无数据 `null` |
| cumulativeFlow | Number? | 累计流量（万m³，3 位小数截断）：不传 `startTime` = 当年累计；传 = 该时刻起的区间累计 |
| vol | Number? | 电压（V）；无数据 `null` |
| lon | Number? | 站点经度（点位坐标）；无档案关联 `null` |
| lat | Number? | 站点纬度（点位坐标）；无档案关联 `null` |
| isOnline | Boolean | 在线状态：MQTT 站 30 分钟、RabbitMQ 站 70 分钟无更新判离线 |
| holes | Array | 各闸孔数据（按闸孔号升序） |

**holes[].字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| gateNo | String | 闸孔编号，如 `"1"`、`"2"`、`"3"` |
| openDegree | Number? | 该孔闸门开度（m）；无数据 `null` |
| status | String | 闸门状态（页面编码，如 `#1#`） |

### 1.3 调用细节说明

1. **点位全集**：不传参返回全部闸站点位（约 10 个）；点位清单可用 `GET /gate-monitor/sites` → `[{site, siteName}]` 或 `GET /station-metrics/sites?type=gate`；
2. **流量联动**：最新报文批次的闸孔开度、闸前 / 闸后水位全部无有效值（`null` / `-999` / `-9991` / `0`）时，`q` 与 `cumulativeFlow` 一并返回 `null`（避免"水位无值而流量有值"的误导展示）；
3. **单位口径**：累计流量统一 **万m³**（库中 m³ ÷ 10000，3 位小数截断）；瞬时流量 m³/s 不换算；
4. 每条记录携带渠系 `canalId` / `canalName`（未关联渠系为 `null`）。

## 二、雨量监测点位

> 点位来源：「雨量监测」页面在用接口；每个雨量站一条最新记录（点位 = 雨量站）。

### 2.1 调用细节

**请求方式**：`GET`

**请求路径**：`/st-pptn-r/gq-rainfall`

| 参数 | 必填 | 格式 | 说明 |
|------|:--:|------|------|
| page / size | 否 | long | 分页：页码 / 每页条数，默认 1 / 20（站点少，默认一页取全） |
| stcd | 否 | String | 站点编号（筛选单个站点）。**不传 = 全部灌区雨量点位（排除水库 13 站）；传 = 仅该站**（含水库站，支持单独查询库上站点） |
| canalId | 否 | String | 渠系 id。按渠系树过滤（含全部子孙渠系）；可与 stcd、时间区间同传取交集 |
| startTime | 否 | `yyyy-MM-dd HH:mm:ss` | 起始时间（含）；限定「最新数据」落在区间内 |
| endTime | 否 | `yyyy-MM-dd HH:mm:ss` | 截止时间（含） |

**调用示例**：

```
GET /st-pptn-r/gq-rainfall?page=1&size=20
GET /st-pptn-r/gq-rainfall?stcd=9000000136
GET /st-pptn-r/gq-rainfall?canalId=7FtFhET9bThVWf3dUGI&page=1&size=20
```

### 2.2 响应

分页壳（`{total, current, size, pages, records}`），`records` 每站点一条；示例 1 条：

```json
{
  "total": 6,
  "current": 1,
  "size": 20,
  "pages": 1,
  "records": [
    {
      "stcd": "9000000136",
      "id": "YiSfpfSjFTep4pnflU2",
      "stnm": "渠首管理所",
      "canalId": "fXfNxtwluZN31ylT8UD",
      "canalName": "总干渠",
      "lon": 116.264518,
      "lat": 30.44919,
      "tm": "2026-09-08T18:20:00",
      "drp": 0.0,
      "dyp": 177.5,
      "rain1h": 0.0,
      "rain3h": 0.0,
      "rain6h": 0.0,
      "dailyDyp": 0,
      "vol": 14.43,
      "isOnline": true
    }
  ]
}
```

**records[].字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String | 站点编号（点位主键） |
| id | String | 站点档案 id（与闸门点位 `siteId` 同为站点档案主键） |
| stnm | String | 站点名称 |
| canalId | String? | 所属渠系 id；未关联渠系为 `null` |
| canalName | String? | 所属渠系名称；未关联渠系为 `null` |
| lon / lat | Number? | 站点经度 / 纬度（点位坐标）；无档案关联 `null` |
| tm | String | 最新监测时间（ISO） |
| drp | Number | 当前降雨量（mm）= 当前水文日累计（DYP 正向增量） |
| dyp | Number | 累计雨量（mm）= RTU 安装至今总累计（永不归零） |
| rain1h / rain3h / rain6h | Number | 最近 1 / 3 / 6 小时时段雨量（mm，DYP 差） |
| dailyDyp | Number | 昨日雨量（mm，最近一个完整水文日累计） |
| vol | Number | 电压（V）；无数据 `null` |
| isOnline | Boolean | 在线状态（仅实时列表输出；MQTT 站 30 分钟、RabbitMQ 站 70 分钟无更新判离线，水库站按档案状态） |

### 2.3 调用细节说明

1. **点位口径**：默认返回灌区雨量点位（排除水库 13 站）；如需单独查询水库雨量站，显式传 `stcd` 即可；
2. 时段雨量计算：`rainNh = max(0, 当前 DYP − N 小时前最后一条 DYP)`，传感器归零时增量自动取 0；
3. `isOnline` 为条件输出字段：实时列表（本接口）有值，历史 / 图表接口不输出。

## 三、流量监测点位

> 点位来源：「流量监测」页面在用接口；每个站点一条最新记录（点位 = 流量站）。

### 3.1 调用细节

**请求方式**：`GET`

**请求路径**：`/flow-monitor/monitoring`

| 参数 | 必填 | 格式 | 说明 |
|------|:--:|------|------|
| stcds | 否 | String | 站点编号，多个逗号分隔（如 `9000000001,9000000004`）；不传 = 全部流量点位 |
| canalId | 否 | String | 渠系 id。按渠系树过滤（含全部子孙渠系）；可与 stcds、时间区间同传取交集 |
| startTime | 否 | `yyyy-MM-dd HH:mm:ss` | 起始时间（含）；只在此区间内取各站最新一条 |
| endTime | 否 | `yyyy-MM-dd HH:mm:ss` | 截止时间（含） |

**调用示例**：

```
GET /flow-monitor/monitoring                                     # 全量流量点位
GET /flow-monitor/monitoring?stcds=9000000001                    # 单点位（北干渠进水闸）
GET /flow-monitor/monitoring?canalId=7FtFhET9bThVWf3dUGI         # 按渠系取点位（含子孙渠系）
```

### 3.2 响应

数组，每个站点一条（全站约 107 个流量站点 / 测点）；示例 1 条：

```json
[
  {
    "stcd": "9000000001",
    "site": "9000000001",
    "siteId": "4Ieu32Stnz8dTD8S8GD",
    "stnm": "北干渠进水闸",
    "canalId": "fXfNxtwluZN31ylT8UD",
    "canalName": "总干渠",
    "lon": 116.2345,
    "lat": 30.5123,
    "tm": "2026-09-08T18:20:00",
    "q": 11.891,
    "tf": 80.143,
    "cumulativeFlow": 1728.026,
    "vol": 12.89
  }
]
```

**字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String? | 站点编号（点位主键；MQTT 站无编号时为 `null`，此时用 `site` 兜底） |
| site | String | 站点标识（= stcd 或站点 UUID），查询 / 筛选用，不用于展示 |
| siteId | String? | 站点档案主键（站点表 `id`）；档案缺失为 `null` |
| stnm | String | 站点名称 |
| canalId | String? | 所属渠系 id；未关联渠系为 `null`（老站点按 stcd 匹配档案补齐） |
| canalName | String? | 所属渠系名称；未关联渠系为 `null` |
| lon / lat | Number? | 站点经度 / 纬度（点位坐标）；无档案关联 `null`（老站点按 stcd 补位） |
| tm | String | 监测时间（ISO） |
| q | Number? | 瞬时流量（m³/s）；无数据 `null` |
| tf | Number? | 累计流量（万m³，3 位小数截断 = 库中 m³ 原值 ÷ 10000） |
| cumulativeFlow | Number? | 累计流量（万m³）：不传 `startTime` = 当年累计；传 = 该时刻起的区间累计 |
| vol | Number? | 电压（V）；无数据 `null` |

### 3.3 调用细节说明

1. **点位主键** = `COALESCE(stcd, site)`：MQTT 站无编号时 `stcd` 为 `null`，用 `site`（站点 UUID）作主键；
2. **累计流量单位口径**：库中 `tf` / `ytf` / `ttf` 均为 m³ 原值，接口统一按 **万m³** 输出（÷ 10000，3 位小数截断）；瞬时流量 `q` 保持 m³/s；
3. canalId 过滤对老站点按 `stcd` 匹配站点档案补齐渠系后过滤（接口内部处理，对接方无感知）。

| stcd | String? | 测站编码（点位主键；无编码站点为 `null`，用 `site` 兜底） |
| site | String | 站点标识（= stcd 或站点 UUID），查询 / 筛选用，不用于展示 |
| siteId | String? | 站点档案主键（站点表 `id`）；档案缺失为 `null` |
| stnm | String | 站点名称 |
| canalId | String? | 所属渠系 id；未关联渠系为 `null`（老站点按 stcd 匹配档案补齐） |
| canalName | String? | 所属渠系名称；未关联渠系为 `null` |
| lon / lat | Number? | 站点经度 / 纬度（点位坐标）；无档案关联 `null`（老站点按 stcd 补位） |
| tm | String | 监测时间（ISO） |
| mten ~ mhundred | Number? | 10 / 20 / 30 / 40 / 50 / 60 / 80 / 100 厘米土壤含水量 |
| vol | Number? | 电压（V）；仅 monitoring 返回（history 为 `null`） |

### 4.3 调用细节说明

1. **含水量哨兵值（与水质口径不同，注意区分）**：`-9991` 设备异常、`-999` 设备不存在，后端**透传**（前端分别展示 `--` / 不展示）；`null` = 无数据；
2. 每条记录携带渠系 `canalId` / `canalName`（老站点按 stcd 补位，未关联为 `null`）；
3. 点位主键 = `COALESCE(stcd, site)`（无编号站点回退 site UUID，筛选参数两种都能传）。

## 六、点位筛选与调用细节

### 6.1 渠系树过滤（canalId，本次新增）

- 传 `canalId` 返回该渠系及其**所有子孙渠系**下的点位（含自身）：渠系管理表按 `cyjihq` → 父 id 建树（NULL = 顶级），服务端 BFS 收集全部子孙渠系 id 后过滤；
- `canalId` 在渠系表中不存在时仅匹配自身（不报错）；
- 可与站点筛选（`site` / `stcd` / `stcds`）、时间参数同传取交集；
- 每条记录携带 `canalId` / `canalName`（未关联渠系为 `null`）。

### 6.2 站点筛选参数对照

| 接口 | 参数 | 形式 | 说明 |
|------|------|------|------|
| 水位 / 闸门 | `site` | 单个 | 站点 UUID（= 响应 `siteId`） |
| 雨量 | `stcd` | 单个 | 站点编号 |
| 流量 / 墒情 / 水质 | `stcds` | 多个（逗号分隔） | 站点标识 = `COALESCE(stcd, site)`；无编号站点可传 site UUID |

### 6.3 时间筛选参数对照

| 接口 | 参数 | 格式 |
|------|------|------|
| 水位 / 闸门、流量、雨量 | `startTime` / `endTime` | `yyyy-MM-dd HH:mm:ss`（含边界） |
| 墒情 | `date` | `yyyy-MM-dd`（该日左闭右开区间） |
| 水质 | `startDate` / `endDate` | `yyyy-MM-dd`（含尾日，左闭右开） |

### 6.4 异常值与缺失值处理

- 各接口对哨兵值处理口径不同：墒情 `-999` / `-9991` **透传**；水质 `-999` 转 `null`、`-9991` 透传；流量 / 闸门按各自字段表口径；
- `null` = 无数据（**不返回 0**）；
- **坐标缺失**：`lon` / `lat` 为 `null` 表示该点位未关联站点档案（无坐标），三维打点建议跳过或落默认位置，待档案补齐后自动恢复。

### 6.5 调用建议

- 刷新：五接口均为实时查询（无缓存），按 60s 间隔全量拉取即可；
- 全量场景一次取走：monitoring 接口不传筛选参数即返回全量点位 + 最新值；雨量接口如需加大 `size`（如 `size=100`）可确保单页取全；
- 增量场景：可按 `canalId`（渠系 / 片区）或 `stcds`（点位清单）过滤，降低响应体量。
