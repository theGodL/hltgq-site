# 应急通知导航提示接口

导航页需要展示「应急响应 / 响应解除」提示，点击跳转「应急管理-应急通知」。
本期只提供后端只读接口，**前端负责展示与跳转**；通知的增删改仍由低代码平台表单完成。

- 数据源：应急通知 `t_auto_hltgq_bcmxdv_lmqaew`（只读）
- 接口：`GET /emergency-notice/nav-tip`（无参数；**生产环境统一加 `/hltgq-site` 前缀**，需登录会话）
- 权限：与应急保障同口径，所有登录用户可用

---

| 响应类别 `vqpwue` | 编码 | 通知事项 `pxkzdz` | 编码 | 市级响应等级 `sycosi` | 编码 |
|---|---|---|---|---|---|
| 防汛 | `#1#` | 启动响应 | `#1#` | Ⅰ级 | `#1#` |
| 抗旱 | `#vtsx#` | 升级响应 | `#ifde#` | Ⅱ级 | `#ggdd#` |
| 其他 | `#aivs#` | 降级响应 | `#sjib#` | Ⅲ级 | `#mytc#` |
|  |  | 终止响应 | `#doga#` | Ⅳ级 | `#bylw#` |
|  |  | 补充工作要求 | `#tckv#` |  |  |

通知状态 `cgkpil`：草稿 `#1#` / **已发布 `#ucpd#`** / 已终止 `#mevt#`。

> **注意区分两个「终止」**：
> - 通知状态「已终止」（`cgkpil=#mevt#`）表示该条通知作废，**不参与**导航提示；
> - 通知事项「终止响应」（`pxkzdz=#doga#`）表示该响应类别已解除，**是**导航提示「响应解除」的来源。

## 2. 判定口径（后端已实现，前端不需重算）

1. 只取「已发布」通知；草稿、已终止不参与。
2. 按**响应类别**分组，各类别独立判定（防汛、抗旱、其他可同时存在不同状态）。
3. 每类取**上级发布时间**最近的一条（`innfii` 为空时回退录入时间 `created_at`）作为当前状态：
   - 事项 = 终止响应 → 该类别 `release`（响应已解除）；
   - 其他事项（启动/升级/降级/补充工作要求）→ 该类别 `response`（响应中）。
4. 响应中时的等级取该类别**最近一次非空等级**（「补充工作要求」通常不填等级，需回溯）；
   解除时取终止通知自身等级（可能为空）。
5. `items` 排序：响应中在前、已解除在后；同状态按最新发布时间倒序。
6. **不做过期过滤**：提示展示多久（如解除提示展示 3 天）属前端展示口径。

## 3. 返回结构

| 字段 | 类型 | 说明 |
|---|---|---|
| `hasTip` | boolean | 是否有提示（`items` 非空） |
| `tipType` | string | 汇总类型：`response` 响应中（优先）/ `release` 全部已解除 / `none` 无提示 |
| `appCode` | string | 应用编码 `bcmxdv`（跳转用） |
| `pageCode` | string | 表单编码 `lmqaew`（跳转「应急管理-应急通知」用） |
| `items` | array | 各类别当前状态，无提示时为空数组 |

`items[]` 字段：

| 字段 | 说明 |
|---|---|
| `noticeId` | 通知主键 |
| `title` | 通知标题 |
| `categoryCode` / `categoryName` | 响应类别编码 / 中文 |
| `status` / `statusName` | 该类别状态：`response` 应急响应中 / `release` 响应已解除 |
| `itemCode` / `itemName` | 最近一条已发布通知的事项编码 / 中文 |
| `levelCode` / `levelName` | 当前响应等级编码 / 中文（Ⅰ级~Ⅳ级，可能为空串） |
| `publishUnit` | 上级发布单位（可能为 null） |
| `publishTime` | 上级发布时间 `yyyy-MM-dd HH:mm`（空值回退录入时间） |
| `tipText` | 建议文案，可直接展示 |

> 接口只返回导航提示所需字段。上级文件文号、通知内容（富文本）、灌区落实要求等详情，
> 点击跳转到表单页查看。

## 5. 前端对接要点

- 导航页加载时请求一次即可；如需定时刷新，建议轮询间隔 ≥ 5 分钟（无实时推送）。
- `tipType` 决定整体样式：`response` 用警示色，`release` 用中性/恢复色，`none` 不渲染。
- `items` 逐条展示（可能同时存在多类别）；每条直接用 `tipText`，或用字段自行拼装。
- 点击任一提示：按平台既有表单路由，用 `appCode=bcmxdv` + `pageCode=lmqaew` 跳转到
  「应急管理-应急通知」。
- 展示时长、是否可关闭、同一类别多条如何折叠均由前端决定，后端每次返回当前事实。

## 6. 联调提示

- 当前库中应急通知仅 1 条测试数据且状态为「已终止」，接口返回
  `hasTip=false, tipType=none`；需在低代码表单发布一条通知后才有提示。
- 验证顺序建议：发布「启动响应」→ 提示响应中；再发布同类别「终止响应」→ 提示解除；
  再发布「草稿」→ 不改变提示。
