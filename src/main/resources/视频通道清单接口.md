# 视频通道清单接口（GET /external/video-devices）

> 面向三方视频接入的**逐通道基础信息**接口：一次全量返回（或**按站点名称模糊筛选**）全部视频设备的
> 通道号、设备名称、设备状态、经纬度、所属站点（编号/名称/状态/经纬度/管理单位）等接入所需数据。
>
> 2026-10-16 新增；生产环境已上线并实测复核通过（见文末「线上复核记录」）。
> 管理所级汇总仍用原 `/external/video-summary`（未改动）。

## 请求

```
GET http://220.179.1.110:8081/hltgq-site/external/video-devices
```

无参数时一次全量返回（不分页）。

| 参数 | 必填 | 说明 |
|------|------|------|
| siteName | 否 | **站点名称模糊词**（按返回字段 `siteName` 即所属站点名称匹配，如 `双庙湖` 命中「双庙湖管理所」「双庙湖节制闸」「双庙湖渡槽」）；不传或空白 = 不筛选（全量）。2026-10-16 库内直查实测：`双庙湖`→7 台、`湖`→45 台、`管理所`→33 台、不存在的词→0 台 |

### 鉴权（与其他 /external 接口一致）

需携带有效**登录会话**。会话 ID 形如 `dev_hltgq_session:xxxxxxxx`（平台登录后获取），
以下三种传法任选其一：

| 传法 | 示例 | 说明 |
|------|------|------|
| Header `X-Session-Id` | `X-Session-Id: dev_hltgq_session:xxxxxxxx` | 优先取用 |
| Header `Authorization` | `Authorization: dev_hltgq_session:xxxxxxxx` | 可带 `Bearer ` 前缀 |
| Cookie `sessionId` | `sessionId=dev_hltgq_session:xxxxxxxx` | 注意 Cookie 名为 `sessionId`，值为完整会话串 |

会话获取：`POST /auth/login`（key/secret）返回 sessionId；未携带或会话失效返回 401。

curl 示例：

```
# 全量（224 台）
curl -H "X-Session-Id: dev_hltgq_session:xxxxxxxx" "http://220.179.1.110:8081/hltgq-site/external/video-devices"

# 按站点名称模糊查询（「双庙湖」→ 7 台）
curl -H "X-Session-Id: dev_hltgq_session:xxxxxxxx" "http://220.179.1.110:8081/hltgq-site/external/video-devices?siteName=双庙湖"
```

中文参数建议做 URL 编码（`双庙湖` = `%E5%8F%8C%E5%BA%99%E6%B9%96`），多数客户端会自动处理。

| 字段 | 类型 | 说明 |
|------|------|------|
| code | String | 通道号（三方视频平台对接主键，形如 `1000219$1$0$3`） |
| name | String | 设备名称（即通道名称，原样返回，**多数含尾部 `#`**） |
| isOnline | Boolean | 是否在线（`status` = `#1#` 为 true，其余 false） |
| status | String | **设备状态**（原值：`#1#` 在线 / `#2#` 离线） |
| lon / lat | Number? | **站点经度 / 站点纬度**（所属站点档案坐标；档案未配置为 null，224 台中 174 台有值） |
| deviceLon / deviceLat | Number? | **设备经度 / 设备纬度**（设备自身坐标列；**当前全部未登记（null）**，设备档案登记坐标后自动返回） |
| org | String | 管理所（安装位置按「-」截取首段，空归「未知」） |
| location | String | 安装位置原文（如「双庙湖电站-信息化机房」） |
| siteId | String | 所属站点档案主键 `id` |
| siteName | String | 所属站点名称 |
| stcd | String | 所属站点编号（档案未配置编号时为 null，224 台中 36 台为空） |
| siteStatus | String | **站点状态**（档案人工维护值：`#1#` 在线 / `#2#` 离线；与设备状态相互独立） |
| managementUnit | String? | 所属站点管理单位名称（档案未配置为 null，224 台中 34 台为空） |

## 数据口径

- **设备范围**：设备表 `t_auto_hltgq_water_device` 中 `type` 含视频编码（`#5#`）的全部设备，一台设备一行；
- **站点名称筛选**：`siteName` 非空时按所属站点名称模糊匹配（包含即命中）；不传或空白 = 全量（行为与新增前完全一致）；
- **排序**：按安装位置、设备名称、通道号排序（中文排序）；
- **设备状态**（`status`）取设备表原值；**站点状态**（`siteStatus`）取所属站点档案 `zebpsu` 原值——
  两者编码口径一致（`#1#` 在线 / `#2#` 离线），**原样返回不做转换**；设备状态为设备上报状态、
  站点状态为档案人工维护状态，两者相互独立；
- **站点经纬度**（`lon`/`lat`）取设备所属站点档案坐标；**设备经纬度**（`deviceLon`/`deviceLat`）
  取设备表自身坐标列（预留列，当前全部未登记 → null，登记后自动返回）；
- 空值如实返回、不做清洗补全（null = 该数据项未配置）。
