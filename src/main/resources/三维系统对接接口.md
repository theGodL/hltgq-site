# 三维系统对接接口（外部数据服务）

> 适用范围：三维系统（大屏 / 数字孪生）数据对接。`/external/*` 为本次新增的专用接口；天气、雨量复用现有页面接口（第七章、第八章）。
>
> **状态标注**：全部 8 个接口**✅ 已上线验证**（2026-09-05，线上实测 HTTP 200、数据自洽）：6 个 `/external/*` 接口 + 复用接口天气（第七章）、雨量（第八章）。附录待确认口径定稿后逐项更新。
>
> 本文档面向对接方：正文只讲「请求什么、拿到什么」；后端数据来源与口径见各接口「数据口径」说明。

---

## 通用约定（对接方必读）

| 约定 | 说明 |
|------|------|
| 鉴权 | 默认走登录会话（`Authorization` 头）；是否对三维系统开放免鉴权白名单**待确认**（见附录） |
| null 语义 | 无数据返回 `null`，**不返回 0**（0 = 真实值为 0）；对接方按 `null` 处理缺数。例外：逐日趋势数组为保持日期连续，无记录补 0（见第四章） |
| 数字精度 | 瞬时流量 3 位小数、水位 2 位小数、雨量 2 位小数，均**截断不四舍五入**（水位/雨量不足位补零，如 42.70）；计数类为整数 |
| 时间格式 | 接口参数日期 `yyyy-MM-dd`；时间戳 `yyyy-MM-dd HH:mm:ss`（复用接口例外见各章说明） |
| 频率 | `/external/*` 为实时查询（无缓存、无轮询任务）；天气接口带 Redis 缓存（TTL 约 10 分钟）。对接方按 60s 间隔刷新即可 |

## 一、闸门类型数量

```
GET /external/gate-type-count
```

无参数。响应：

```json
{
  "items": [
    { "type": "节制闸", "count": 0 },
    { "type": "分水口", "count": 0 },
    { "type": "退水闸", "count": 0 },
    { "type": "倒虹吸", "count": 0 }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| items[].type | String | 闸门类型（固定 4 项，顺序固定） |
| items[].count | Number | 数量；**暂恒 0**（闸门类型分类数据待三方收集补录，到位后改为真实统计） |

## 二、渠首进水闸实时数据

```
GET /external/intake-gate
```

无参数。响应：

```json
{
  "stcd": "CAYQ739MiBWMg9gQvyi",
  "stnm": "渠首进水闸",
  "upZ": 42.71,
  "downZ": 42.23,
  "q": 47.017,
  "tm": "2026-09-05 21:00:00",
  "managementUnit": "花凉亭灌区"
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd / stnm | String | 站点标识 / 名称（固定：渠首进水闸） |
| upZ | Number? | 闸前（上游）水位（m，**2 位小数截断补零**）；取闸门表 `up_z` 最新一条，无数据 null |
| downZ | Number? | 闸后（下游）水位（m，**2 位小数截断补零**）；取闸门表 `down_z` 最新一条，无数据 null |
| q | Number? | 瞬时流量（m³/s，**3 位小数截断**）；取流量表最新 `q`，无数据 null |
| tm | String | 数据时间（取水位/流量中较新者） |
| managementUnit | String | 管理单位（固定「花凉亭灌区」） |

数据口径：水位源 `t_auto_hltgq_water_gate`（up_z/down_z），流量源 `t_auto_hltgq_water_wt_nfo`（q）。
精度口径（业主规则）：瞬时流量 3 位小数、水位 2 位小数，均截断不四舍五入；无效值 -999/-9991 返回 null。

## 三、巡检汇总

```
GET /external/patrol-summary
```

无参数。响应：

```json
{
  "patrolCount": 128,
  "scheduleCount": 45,
  "finishedCount": 31,
  "maintenanceBudget": 0,
  "maintenanceCost": 0
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| patrolCount | Number | 累计巡检次数（巡检记录已提交，排除草稿，全量） |
| scheduleCount | Number | 巡检计划总数 |
| finishedCount | Number | 完成巡检数（巡检计划状态 = 已完成） |
| maintenanceBudget | Number | 维养预算（万元）；**暂恒 0**（数据源待确认，见附录） |
| maintenanceCost | Number | 维养成本（万元）；**暂恒 0**（数据源待确认，见附录） |

## 四、巡检/问题逐日趋势

```
GET /external/daily-trend?startDate=2026-08-01&endDate=2026-08-31
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| startDate | String | 否 | 起始日期 `yyyy-MM-dd`（含）；不传默认近 30 天起点 |
| endDate | String | 否 | 截止日期 `yyyy-MM-dd`（含）；不传默认今天 |

响应：

```json
{
  "dates":  ["2026-08-01", "2026-08-02", "2026-08-03"],
  "patrol": [3, 0, 2],
  "issue":  [1, 2, 0]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| dates | String[] | 横轴逐日标签（含首尾，`yyyy-MM-dd`） |
| patrol | Number[] | 逐日巡检次数（已提交记录按巡检时间取日期聚合），无记录补 0 |
| issue | Number[] | 逐日问题数量（问题按发现时间取日期聚合，全状态），无记录补 0 |

要点：三数组等长；区间上限 366 天、日期格式错误、startDate 晚于 endDate 均报 400。

## 五、问题状态统计

```
GET /external/issue-stats
```

无参数。响应：

```json
{
  "handled": 7,
  "unrectified": 9,
  "emergencyTotal": 16,
  "resolved": 7,
  "unresolved": 9
}
```

| 字段 | 类型 | 口径 |
|------|------|------|
| handled | Number | 已处理 = 问题状态「已关闭」 |
| unrectified | Number | 未整改 = 「处理中」+「已转工单」 |
| emergencyTotal | Number | 突发事件 = 问题总数（全状态） |
| resolved | Number | 已解除响应 = 已处理问题数（= handled，**映射待确认**） |
| unresolved | Number | 未解除响应 = 处理中 + 已转工单（= unrectified，**映射待确认**） |

要点：两组口径（问题处理 / 应急响应）数据同源（问题表），后三项名称与映射关系见附录待确认项。

## 六、视频监测按管理所聚合

```
GET /external/video-summary
```

无参数。响应：

```json
[
  { "org": "渠首管理所", "total": 10, "online": 8, "offline": 2 },
  { "org": "汪元管理所", "total": 10, "online": 8, "offline": 2 }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| org | String | 管理所名称：取视频设备安装位置首段（「汪元管理所-汪元节制闸下游」→「汪元管理所」） |
| total | Number | 该管理所视频设备总数 |
| online / offline | Number | 在线数 / 离线数（total = online + offline） |

数据口径：设备表 `type` 含视频编码的设备；安装位置 `wlcvig` 按「-」截取首段归组；运行状态 `#1#` = 在线、其他 = 离线。按管理所名称排序。

## 七、天气预报（复用现有接口）

```
GET /weather/hourly?lon={经度}&lat={纬度}&startDate={今天}&endDate={今天}
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| lon / lat | Number | 是 | 坐标（WGS-84，与天地图一致） |
| startDate / endDate | String | 否 | `yyyy-MM-dd`；展示今天数据传 startDate=endDate=今天 |
| location | String | 否 | 站点名称 |

响应：逐小时天气列表（最新在前）：

```json
[
  {
    "id": 1, "date": "2026-09-05", "hour": "23:00", "location": "南排",
    "weather": "晴朗", "temperature": 22, "rainfall": 0.00,
    "windDirection": "北西北风", "windLevel": 1, "windSpeed": 6,
    "humidity": 87, "weatherIcon": "0"
  },
  {
    "id": 2, "date": "2026-09-05", "hour": "22:00", "location": "南排",
    "weather": "晴朗", "temperature": 23, "rainfall": 0.00,
    "windDirection": "北风", "windLevel": 1, "windSpeed": 5,
    "humidity": 81, "weatherIcon": "0"
  }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Number | 序号（最新在前，从 1 重新编号） |
| date / hour | String | 日期 `yyyy-MM-dd` / 小时 `HH:mm` |
| location | String | 站点名称 |
| weather | String | 天气描述（中文） |
| temperature | Number | 气温 ℃（整数） |
| rainfall | Number | 降雨量 mm，2 位小数（截断，不四舍五入） |
| windDirection | String | 风向（16 方位中文，如「北西北风」） |
| windLevel | Number | 风力等级（蒲福风级 0~12） |
| windSpeed | Number | 风速 km/h（整数） |
| humidity | Number | 相对湿度 %（整数） |
| weatherIcon | String | 天气代码（Open-Meteo WMO 码，字符串） |

要点：
- 不传 startDate/endDate 时返回全部缓存窗口（近 7 天历史 + 3 天预报）；传 `startDate=endDate=今天` 取今天全天逐小时
- 「今天是第二天」的展示口径**待确认**（见附录）；当前默认取今天全天逐小时数据
- 若三维系统需免坐标调用，后续增加 `/external/weather-today` 薄包装（坐标取后端配置默认值）

## 八、雨量日聚合（复用现有接口）

```
GET /st-pptn-r/gq-daily-rainfall?startDate=2026-09-01&endDate=2026-09-05
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|:--:|------|
| startDate / endDate | String | 否 | `yyyy-MM-dd`；不传默认当天 |

响应（双视角：stations 实时快照 + days 逐日透视表）：

```json
{
  "stations": [
    {
      "stcd": "9000000136", "stnm": "渠首管理所", "id": "YiSfpfSjFTep4pnflU2",
      "latestTm": "2026-09-05T21:20:00", "latestDrp": 0.00
    },
    {
      "stcd": "9000000137", "stnm": "集岭管理所", "id": "JsrIMB8v9oKi0MpT79N",
      "latestTm": "2026-09-05T21:20:00", "latestDrp": 0.00
    }
  ],
  "days": [
    {
      "day": "2026-09-01 08:00:00",
      "values": { "9000000136": 12.34, "9000000137": 0.00 },
      "avg": 6.17
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| stations[].stcd / stnm | String | 站点编号 / 名称 |
| stations[].id | String | 站点主键 |
| stations[].latestTm | String | 最新观测时间（ISO 格式 `yyyy-MM-ddTHH:mm:ss`，与 `/external/*` 的 `yyyy-MM-dd HH:mm:ss` 不同） |
| stations[].latestDrp | Number | 当前降雨量 mm = 最新观测所在水文日的累计雨量，2 位小数截断补零 |
| days[].day | String | 水文日标签 `yyyy-MM-dd 08:00:00`（该标签代表前一水文日 8:00 至当日 8:00 的雨量，8 点整记录归当日标签） |
| days[].values | Object | 站点编号 → 当日雨量 mm（2 位小数截断补零；无记录 0.00） |
| days[].avg | Number | 当日各站平均值 mm（2 位，银行家舍入，老系统口径） |

要点：

- 柱状图直接取 `days[]`：x 轴 = `day`，每站点一个柱序列（y 轴 = `values[站点编号]`）
- 站点口径：灌区雨量站点（排除水库 13 站）；如需水库站点柱状图，改用 `GET /st-pptn-r/reservoir-rainfall`（12 个固定水库站点，结构相同）
