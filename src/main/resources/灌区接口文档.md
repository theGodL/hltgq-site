# 灌区监测接口文档

> 面向前端，生产环境路径统一加 `/hltgq-site` 前缀
> 涵盖灌区雨量、水位、水库雨情、取水量、站点综合指标等模块

---

## 一、灌区雨量分页

每站点仅返回最新一条，含 1h / 3h / 6h 三档降雨增量。

### 请求

```
GET /st-pptn-r/gq-rainfall
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:--:|--------|------|
| page | long | 否 | 1 | 页码 |
| size | long | 否 | 20 | 每页条数 |
| stcd | String | 否 | — | 站点编号（筛选单个站点） |
| startTime | String | 否 | — | 监测起始时间 `yyyy-MM-dd HH:mm:ss` |
| endTime | String | 否 | — | 监测截止时间 `yyyy-MM-dd HH:mm:ss` |

### 调用示例

```
/hltgq-site/st-pptn-r/gq-rainfall?page=1&size=20
/hltgq-site/st-pptn-r/gq-rainfall?stcd=9000000137&startTime=2026-07-20+08:00:00&endTime=2026-07-30+07:59:59
```

### 响应

```json
{
  "total": 15,
  "current": 1,
  "size": 20,
  "records": [
    {
      "stcd": "9000000137",
      "id": "uuid-xxx",
      "stnm": "某某雨量站",
      "tm": "2026-07-29 10:00:00",
      "drp": 125.5,
      "rain1h": 2.3,
      "rain3h": 5.1,
      "rain6h": 8.7
    }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| total | long | 总记录数 |
| current | long | 当前页码 |
| size | long | 每页条数 |
| records | Array | 数据列表 |

**records[].字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String | 站点编号 |
| id | String | 站点 UUID |
| stnm | String | 站点名称 |
| tm | String | 最新监测时间 |
| drp | Number | 实时 DRP 累计值 (mm) |
| rain1h | Number | 近 1 小时降雨量 (mm)。`null` 表示历史无 1h 前数据 |
| rain3h | Number | 近 3 小时降雨量 (mm)。`null` 表示历史无 3h 前数据 |
| rain6h | Number | 近 6 小时降雨量 (mm)。`null` 表示历史无 6h 前数据 |

### 计算规则

```
rainNh = max(0, 当前DRP − N小时前最后一条DRP)
```

- 传感器归零（DRP 骤降）时增量自动取 0
- 历史记录缺失时增量返回 `null`（非 0）

## 二、灌区雨量变化图表

单站点小时级增量 + 累计雨量，**前端双 Y 轴图表直接消费**。

### 请求

```
GET /st-pptn-r/gq-rainfall-chart
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:--:|--------|------|
| stcd | String | **是** | — | 站点编号 |
| startTime | String | 否 | 7 天前整点 | 起始时间 `yyyy-MM-dd HH:mm:ss` |
| endTime | String | 否 | 当前整点小时 | 截止时间 `yyyy-MM-dd HH:mm:ss` |

### 调用示例

```
/hltgq-site/st-pptn-r/gq-rainfall-chart?stcd=9000000137
/hltgq-site/st-pptn-r/gq-rainfall-chart?stcd=9000000137&startTime=2026-07-20+08:00:00&endTime=2026-07-25+08:00:00
```

### 响应

```json
{
  "stcd": "9000000137",
  "stnm": "某某雨量站",
  "startTime": "2026-07-22 08:00:00",
  "endTime": "2026-07-29 08:00:00",
  "hours": [
    { "hour": "2026-07-22 08:00", "rainfall": 0.0, "cumulative": 0.0 },
    { "hour": "2026-07-22 09:00", "rainfall": 2.5, "cumulative": 2.5 },
    { "hour": "2026-07-22 10:00", "rainfall": 3.1, "cumulative": 5.6 },
    { "hour": "2026-07-22 11:00", "rainfall": 0.0, "cumulative": 5.6 },
    { "hour": "2026-07-22 12:00", "rainfall": 0.8, "cumulative": 6.4 }
  ]
}
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String | 站点编号 |
| stnm | String | 站点名称 |
| startTime | String | 查询起始时间 |
| endTime | String | 查询截止时间 |
| hours | Array | 小时级数据点（**严格 1h 步长，无缺失**） |

**hours[].字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| hour | String | 小时标签 `yyyy-MM-dd HH:00` |
| rainfall | Number | 该小时内的增量雨量 (mm)。无数据时 = 0 |
| cumulative | Number | 从 startTime 到该小时的**累计**雨量 (mm) |

### 前端图表用法

```javascript
const resp = await fetch(`/hltgq-site/st-pptn-r/gq-rainfall-chart?stcd=${stcd}`);
const { hours } = await resp.json();

// ECharts 双 Y 轴
chart.setOption({
  xAxis:  { data: hours.map(h => h.hour.slice(5, 16)) },       // 只保留 "MM-DD HH:00"
  yAxis:  [
    { name: '实时雨量 (mm)' },
    { name: '累计雨量 (mm)' }
  ],
  series: [
    { name: '实时雨量', type: 'bar',  yAxisIndex: 0, data: hours.map(h => h.rainfall) },
    { name: '累计雨量', type: 'line', yAxisIndex: 1, data: hours.map(h => h.cumulative) }
  ]
});
```

### 计算规则

```
服务端内部逻辑（前端无需关心）：
1. 向前扩展 2h 查询原始 DRP 记录（确保首小时有基线对比）
2. 按时间排序后遍历：
    第一条记录  →  inc = 0
    后续记录    →  inc = max(0, cur.DRP − prev.DRP)
3. 将增量归属到小时桶（HH:00），同一小时的多次上报累加
4. 生成完整小时序列（从 startTime 到 endTime，步长固定 1h）
5. 累计 = 逐小时 rainfall 累加
```

### 边界场景

| 场景 | 表现 |
|------|------|
| 某小时无设备上报 | `rainfall = 0`，`cumulative` 保持上小时值 |
| 传感器归零（DRP 骤降） | 归零时增量 = 0，归零后继续正常计算 |
| 整段时间无数据 | 返回空 `hours: []` |
| 数据断档后恢复 | 恢复后第一条 inc=0，后续恢复累加 |

| | `/gq-rainfall` | `/gq-rainfall-history` |

| 使用场景 | 实时概览表格 | 历史数据表格 / 详情页 |

与 `/gq-rainfall` 完全一致：

```
rainNh = max(0, 该时刻DRP − N小时前最后一条DRP)
```

## 五、水库日雨情

12 个固定水库站点，按水文日（8:00 切分）聚合日雨量。列名：监测日期（按日）、12 个站点、平均值。**后端一次计算，前端直接渲染表格**。

> 别名："水库实时雨情"、"水库日雨情报表"。

### 请求

```
GET /st-pptn-r/reservoir-rainfall
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:--:|--------|------|
| startDate | String | 否 | 当天 | 起始日期 `yyyy-MM-dd` |
| endDate | String | 否 | 当天 | 截止日期 `yyyy-MM-dd` |

### 调用示例

```
/hltgq-site/st-pptn-r/reservoir-rainfall
/hltgq-site/st-pptn-r/reservoir-rainfall?startDate=2026-07-20&endDate=2026-07-29
```

### 响应

```json
{
  "stations": [
    {
      "stcd": "00000001",
      "stnm": "周家河",
      "id": "uuid-xxx",
      "latestTm": "2026-07-29 10:00:00",
      "latestDrp": 125.5
    }
  ],
  "days": [
    {
      "day": "2026-07-28 08:00:00",
      "values": {
        "00000001": 5.2,
        "00000002": 3.1,
        "00000003": 0.0
      },
      "avg": 0.69
    },
    {
      "day": "2026-07-29 08:00:00",
      "values": {
        "00000001": 2.8,
        "00000002": 0.0,
        "00000003": 1.5
      },
      "avg": 0.36
    }
  ]
}
```

### 字段说明

**stations[] — 12 个固定站点信息（按以下顺序排列）：**

| 序号 | stcd | stnm |
|:--:|------|------|
| 1 | 00000003 | 九田 |
| 2 | 00000001 | 周家河 |
| 3 | 00000002 | 姜家寨 |
| 4 | 00000008 | 寺前 |
| 5 | 00000009 | 河图铺 |
| 6 | 00000010 | 下前河 |
| 7 | 00000011 | 鲤鱼墩 |
| 8 | 00000012 | 弥陀 |
| 9 | 00000013 | 白帽 |
| 10 | 00000007 | 花凉亭坝上 |
| 11 | 00000005 | 牛镇 |
| 12 | 00000006 | 马嘶铺 |

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String | 站点编号 |
| stnm | String | 站点名称 |
| id | String | 站点 UUID |
| latestTm | String | 该站点最新观测时间，无数据为 `null` |
| latestDrp | Number | 该站点最新 DRP 值 (mm)，无数据为 `null` |

**days[] — 逐日雨量（水文日维度）：**

| 字段 | 类型 | 说明 |
|------|------|------|
| day | String | 水文日标签 `yyyy-MM-dd 08:00:00` |
| values | Object | 键为 stcd，值为日降雨量 (mm)。无数据站点 = 0，**12 个 key 完整不缺** |
| avg | Number | 该水文日 12 站平均值 (mm)，保留 2 位小数 |

### 前端透视表用法

> 平均值已由后端计算返回，前端直接取值渲染即可。

```javascript
const resp = await fetch('/hltgq-site/st-pptn-r/reservoir-rainfall?startDate=2026-07-20&endDate=2026-07-25');
const { stations, days } = await resp.json();

// 表头：监测日期 + 12 站名称 + 平均值
const thead = `<tr><th>监测日期</th>${stations.map(s => `<th>${s.stnm}</th>`).join('')}<th>平均值 (mm)</th></tr>`;

// 表体：逐行渲染（avg 由后端直接返回，保留 2 位小数）
const tbody = days.map(d => {
  const cells = stations.map(s => {
    const v = d.values[s.stcd] || 0;
    return `<td>${v > 0 ? v.toFixed(1) : ''}</td>`;
  });
  return `<tr><td>${d.day}</td>${cells.join('')}<td>${d.avg.toFixed(2)}</td></tr>`;
}).join('');
```

### 计算规则

完全对齐 `hydro-monitor.html` 的 `buildPptnPivot` 逻辑：

```
1. 向前后各扩展 1 天查询，确保水文日边界（8:00）完整
2. 按站点分组 → 时间升序 → 遍历计算增量
    第一条记录  →  inc = 0
    后续记录    →  inc = max(0, cur.DRP − prev.DRP)
3. 增量归属到水文日桶（getHydroDayLabel 规则）：
    TM 在当日 08:00 ~ 次日 07:59 之间 → 归属到"次日 08:00:00"标签的水文日
4. 同一水文日内同一站点的所有增量累加 → 日降雨量
```

### 水文日切分示意

```
 2026-07-28 08:00 ───────────── 2026-07-29 07:59  →  标签 "2026-07-29 08:00:00"
 2026-07-29 08:00 ───────────── 2026-07-30 07:59  →  标签 "2026-07-30 08:00:00"
```

## 六、水库时段雨情

12 个固定水库站点，按**可配时间间隔**聚合时段雨量，列含每站降雨量 + 平均值。

### 请求

```
GET /st-pptn-r/reservoir-period-rainfall
```

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|:--:|--------|------|
| startDate | String | 否 | 当天 | 起始日期 `yyyy-MM-dd` |
| endDate | String | 否 | 当天 | 截止日期 `yyyy-MM-dd` |
| interval | int | 否 | 60 | 时间间隔（分钟），可选 15/30/45/60/120/180/240/360/480/720/1440 |

### 调用示例

```
/hltgq-site/st-pptn-r/reservoir-period-rainfall?startDate=2026-07-28&endDate=2026-07-29&interval=60
/hltgq-site/st-pptn-r/reservoir-period-rainfall?interval=180
```

### 响应

```json
{
  "stations": [
    { "stcd": "00000001", "stnm": "周家河", ... }
  ],
  "buckets": [
    {
      "time": "2026-07-28 08:00",
      "values": { "00000001": 1.2, "00000002": 0.5, ... },
      "avg": 0.38
    },
    {
      "time": "2026-07-28 09:00",
      "values": { "00000001": 2.3, "00000002": 0.0, ... },
      "avg": 0.62
    }
  ]
}
```

### 字段说明

**stations[]** — 12 个站点信息，与 [五、水库日雨情](#五水库日雨情) 相同

**buckets[] — 时段桶数据：**

| 字段 | 类型 | 说明 |
|------|------|------|
| time | String | 时段标签 `yyyy-MM-dd HH:mm`（interval=60 时为整点） |
| values | Object | 键为 stcd，值为该时段降雨量 (mm)。12 个 key 完整不缺 |
| avg | Number | 该时段 12 站平均值 (mm)，保留 2 位小数 |

### 与日雨情的区别

| | 日雨情 `reservoir-rainfall` | 时段雨情 `reservoir-period-rainfall` |
|------|:--:|:--:|
| 时间维度 | **日**（水文日 08:00 切分） | **可配间隔**（分钟级） |
| 桶标签 | `yyyy-MM-dd 08:00:00` | `yyyy-MM-dd HH:mm` |
| 行平均值 | ✅ `avg` 字段 | ✅ `avg` 字段 |
| 参数 | startDate/endDate | startDate/endDate/**interval** |

### 间隔取值与桶覆盖范围

```
interval=60  → 从 (startDate-1) 08:00 开始，每小时一个桶，到 endDate 08:00 为止
              如 startDate=07-28, endDate=07-29 → 07-27 08:00 ~ 07-29 08:00 共 48 个桶

interval=180 → 同上，但每 3 小时一个桶，共 16 个桶
```

### 计算规则

完全对齐 `hydro-monitor.html` 的 `buildPeriodPivot` + `floorToInterval` 逻辑：

```
1. 向前后各扩展 1 天查询
2. 按站点分组 → 时间升序 → 遍历计算增量（与实时雨情相同）
    第一条  →  inc = 0
    后续    →  inc = max(0, cur.DRP − prev.DRP)
3. floorToInterval：分钟取整到间隔边界（如 08:35 → interval=60 时归属 08:00）
4. 同一时段桶内同一站点的所有增量累加
```

```json
      "yearMonth": "2026-07",
      "tenDay": "上旬",
      "values": { "00000001": 15.2, "00000002": 8.3, ... },
      "avg": 1.85
    },
    {
      "yearMonth": "2026-07",
      "tenDay": "中旬",
      "values": { "00000001": 22.5, "00000002": 12.1, ... },
      "avg": 2.56
    },
    {
      "yearMonth": "2026-07",
      "tenDay": "下旬",
      "values": { "00000001": 18.0, "00000002": 9.7, ... },
      "avg": 2.10
    }
  ]
}
```

### 字段说明

**stations[]** — 12 个站点信息，与 [五、水库日雨情](#五水库日雨情) 相同

**periods[] — 旬数据：**

| 字段 | 类型 | 说明 |
|------|------|------|
| yearMonth | String | 年月 `yyyy-MM` |
| tenDay | String | 旬段：`上旬` / `中旬` / `下旬` |
| values | Object | 键为 stcd，值为该旬累计降雨量 (mm)。12 个 key 完整不缺 |
| avg | Number | 该旬 12 站平均值 (mm)，保留 2 位小数 |

### 旬段划分

| 旬段 | 日期范围 |
|:--:|------|
| 上旬 | 1 日 ~ 10 日 |
| 中旬 | 11 日 ~ 20 日 |
| 下旬 | 21 日 ~ 月末 |

### 计算规则

```
1. 查询指定月份的完整数据（向前后各扩展 1 天保证水文日边界）
2. 按站点分组 → 计算每日水文日雨量（同 reservoir-rainfall）
3. 按旬汇总每日雨量 → 得到旬累计
4. 12 站平均值 = Σ(各站旬累计) / 12
```

## 八、水库极值雨情

| startDate | String | 否 | 当月 1 日 | 起始日期 `yyyy-MM-dd` |
| endDate | String | 否 | 当天 | 截止日期 `yyyy-MM-dd` |

### 调用示例

```
/hltgq-site/st-pptn-r/reservoir-extreme-rainfall
/hltgq-site/st-pptn-r/reservoir-extreme-rainfall?startDate=2026-07-01&endDate=2026-07-31
```

### 响应

```json
[
  {
    "stcd": "00000001",
    "stnm": "周家河",
    "max3h": 12.5,
    "max6h": 18.3,

  },
  {
    "stcd": "00000002",
    "stnm": "姜家寨",
    "max3h": 8.2,
    "max6h": 15.1,
    "max24h": 38.6,
    "max2d": 42.0,
    "max3d": 48.5,
    "max7d": 75.2
  }
]
```

### 字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| stcd | String | 站点编号 |
| stnm | String | 站点名称 |
| max3h | Number | 任意连续 3 小时最大雨量 (mm) |
| max6h | Number | 任意连续 6 小时最大雨量 (mm) |
| max24h | Number | 任意连续 24 小时最大雨量 (mm) |
| max2d | Number | 任意连续 2 天最大雨量 (mm) |
| max3d | Number | 任意连续 3 天最大雨量 (mm) |
| max7d | Number | 任意连续 7 天最大雨量 (mm) |

### 计算规则

```
1. 查询原始 DRP 记录（向前扩展 8 天保证窗口完整）
2. 按站点分组 → 计算小时增量序列
3. 滑动窗口求最大值：
    小时级（3h/6h/24h）→ 直接在小时序列上滑动求和
    天级（2d/3d/7d）→ 先聚合为日序列，再滑动求和
4. 每个站点返回 6 个极值
```

## 附录：通用约定

| 项目 | 约定 |
|------|------|
| 前缀 | 生产环境统一加 `/hltgq-site`，如 `/hltgq-site/st-pptn-r/gq-rainfall` |
| 时间格式 | URL 参数用 `yyyy-MM-dd HH:mm:ss`（空格替换为 `+` 或 `%20`） |
| null | 表示数据不存在或无法计算，需前端自行处理为空值展示 |
| 0 | 表示该时段确实无变化或无降雨 |
