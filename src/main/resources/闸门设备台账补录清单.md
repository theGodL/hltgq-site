# 闸门设备台账补录清单（7 台）

> 目的：消除「闸门监测页」与「大屏概览 / 网络设备监控」之间**闸门台数不一致**的口径差（业主核对必读）。
> 生成时间：2026-09-23（数据为当日全库只读实测）
> 影响接口：`GET /dashboard/overview`、`GET /network-device/summary`；影响页面：大屏概览（闸门开启率）、网络设备监控（闸门分类卡片）
> 不影响：数据统计页（该页只统计站点/设备到报率，不涉及闸门）

---

## 一、问题：同一批闸孔设备，两处口径差 7 台

| 口径 | 取数规则 | 补录前 | 补录后 |
|------|----------|:--:|:--:|
| 大屏 `totalGateCount` / 监控页「闸门」分类 `total` | 设备台账 `t_auto_hltgq_water_device.type LIKE '%#4#%'` | **51** | **58** |
| 大屏 `openGateCount` / 监控页闸门分类「开启」 | 上述设备中近 24h 最新开度 > 0 | **21** | **28** |
| 闸门监测页（站点行 / 开启孔） | 站点档案 `epjutj LIKE '%#4#%'` + 闸门采集表有数据 | 18 站 / **28 个开启孔** | 18 站 / 28 个开启孔（不变） |

**根因**：这 7 台闸孔设备**在设备台账中已建档、采集侧也一直在上报开度**，但台账的「设备类型」（`type`）字段为 `NULL`，因此既不计入「闸门」分类，也不被大屏闸门统计纳入（它们被计入了 `/network-device/summary` 的 `uncategorized` 未分类项）。**不是缺档案、不是缺数据，只是类型字段没维护**，属纯台账数据问题，不涉及代码与 mq 改动。

## 三、补录方式（二选一，在**生产库/平台**执行，只读核对通道不可写）

**方式 A（推荐，平台操作）**：设备台账 → 找到上述 7 台设备 → 编辑「设备类型」→ 勾选/填写为**闸门**（编码 `#4#`）→ 保存。

**方式 B（SQL 直改）**：在业务库执行（`qixiao-apaas` schema），执行前请先做行级备份或确认可回滚：

```sql
-- 影响行数应为 7，执行前可先用下方 SELECT 复核
UPDATE "qixiao-apaas"."t_auto_hltgq_water_device"
SET type = '#4#'
WHERE id IN (
  'MYMFQIuOwZDXNlzcC3QT', 'bzpFqIcKyPPwXU5Zx3n3',
  'TcAShqLLK4LdznXA3xKi', 'bMpR5Au2kMUJalnhxYdM',
  'JFXAF9QHF2vNWt9LckN5', 'R17LnqG1vZ0xd73b808T', 'l2AIaOytGaM4WWKhF5Rl'
);

-- 复核（应为 7）
SELECT COUNT(*) FROM "qixiao-apaas"."t_auto_hltgq_water_device"
WHERE type = '#4#' AND id IN (
  'MYMFQIuOwZDXNlzcC3QT', 'bzpFqIcKyPPwXU5Zx3n3',
  'TcAShqLLK4LdznXA3xKi', 'bMpR5Au2kMUJalnhxYdM',
  'JFXAF9QHF2vNWt9LckN5', 'R17LnqG1vZ0xd73b808T', 'l2AIaOytGaM4WWKhF5Rl');
```

> 若台账 `type` 支持多值（`|` 分隔，如 `#1#|#4#`），只补 `#4#` 即可；以上 7 台现值为 `NULL`，直接赋值不会覆盖其他类型。

## 五、补录后需注意

1. **缓存**：`/network-device/summary` 有 Redis 缓存 60s（key `decision:network-device:summary`），补录后最多等 1 分钟或清 key 即生效；大屏 `/dashboard/overview` 为实时查询，无需处理。
2. **无需 mq 改动**：本项为纯台账类型字段维护。`type` 由平台台账维护，不由报文入库流程写入，因此**不需要 mq 配合**。
3. **不要改站点档案**：闸门监测页按站点档案 `epjutj LIKE '%#4#%'` 判定站点类型，现有 18 站均已正确，**不要为了台数对齐去改站点档案或新建设备**。
4. **校验方式**：
   - 后端日志：`网络设备状态口径：共 357 台，在线 … ；未分类（台账未维护类型）2 台；告警设备 … 台`（未分类应从 9 降为 2）；
   - 页面：`/network-device/summary` 闸门分类卡片显示 58 台（卡片内为在线/离线/告警台数，开启数不在此页）；`/dashboard/overview` `totalGateCount`=58、`openGateCount`=28；闸门监测页开启孔合计 28。
5. **台账口径的长期要求**：新接入闸门设备建档时必须维护「设备类型」，否则会再次落入未分类、导致大屏闸门数与闸门监测页不一致。
